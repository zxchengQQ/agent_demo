# 前端对话模块 功能需求说明书

> **版本**：v1.0 | **基线日期**：2026-07-20 | **状态**：已确认
> **功能负责人**：产品经理 | **优先级**：高
> **关联模块**：agent-demo-web（后端流式接口新增）、前端模块（新建）

---

## 1. 功能概述

### 1.1 功能定位

新增前端模块，实现用户与 AI Agent 的端到端对话交互。第一版聚焦"流式对话 + 本地会话纪录"两大核心能力，让用户通过浏览器即可完成与大模型的实时对话，并能在本地持久化查看所有历史会话纪录。

### 1.2 价值目标

- 提供可视化对话界面，替代 Swagger / curl 调用方式，降低使用门槛
- 流式输出提升用户等待体验，首字响应时间显著缩短
- 本地缓存会话纪录，支持随时回看历史对话，不依赖后端会话存活

### 1.3 用户角色

| 角色 | 使用场景 |
|------|---------|
| **学习者** | 通过界面直观观察 Agent 对话行为，理解 ReAct 循环 |
| **API 调用方** | 体验 Agent 能力后决定是否集成到外部应用 |
| **开发者** | 基于前端模块扩展更多交互能力 |

## 2. 核心业务流程

### 2.1 主流程

```
用户打开页面
  -> 左侧加载本地缓存会话列表（按最后活跃时间倒序）
  -> 右侧默认新建空会话对话框，光标聚焦输入框
  -> 用户输入消息，点击发送
  -> 前端调用后端 SSE 流式接口（携带 sessionId，首次为空）
  -> 后端创建/复用会话，流式返回大模型生成内容
  -> 前端对话框逐字实时显示，输入框禁用 + 显示"停止生成"按钮
  -> 流式完成 -> 完整回复存入本地缓存
  -> 会话列表更新（首条消息生成标题：前 20 字符）
  -> 输入框恢复可用，可继续多轮对话
```

### 2.2 会话切换流程

```
用户点击左侧会话列表某项
  -> 右侧加载该会话所有历史消息（时间正序）
  -> 滚动到最新消息，输入框聚焦
  -> 用户继续发消息 -> 走主流程（携带该会话 sessionId）
```

### 2.3 透明续聊机制（关键）

```
用户在旧会话继续对话（后端会话已超 30 分钟超时）
  -> 前端携带旧 sessionId 调用流式接口
  -> 后端检测会话不存在，自动新建会话，返回新 sessionId
  -> 前端将后续消息关联到新 sessionId
  -> 本地历史纪录仍连续展示在当前会话窗口（用户无感知）
  -> 注意：Agent 实际不包含旧上下文（按新会话处理），仅前端展示连续
```

### 2.4 流式中断流程

```
流式输出进行中
  -> 用户点击"停止生成" / 网络中断
  -> 流式中断，已接收部分内容保留在对话框
  -> 已接收内容作为助手回复存入本地缓存（网络中断时标记为不完整）
  -> 输入框恢复可用，"停止生成"按钮隐藏
```

## 3. 验收标准（AC）

> 编号规则：AC-XXX，三位流水号。后续所有环节（技术方案、任务拆分、TDD 测试）通过编号引用。
> 格式：Given-When-Then。覆盖正常流程（A）、边界/异常（B）、业务规则（C）三类场景。

### A. 正常流程（Happy Path）

#### AC-001：打开页面默认新建空会话

- **Given** 用户首次打开前端页面（本地缓存无会话纪录）
- **When** 页面加载完成
- **Then** 左侧会话列表为空并显示引导提示，右侧显示一个空的新会话对话框，光标聚焦输入框，可直接输入消息

#### AC-002：首次发送消息触发流式输出

- **Given** 用户在空会话输入框输入消息并点击发送
- **When** 前端调用后端流式接口（携带空 sessionId）
- **Then** 后端创建新会话返回新 sessionId，前端对话框逐字实时显示大模型生成内容，输入框禁用并显示"停止生成"按钮

#### AC-003：流式完成后保存会话纪录

- **Given** 流式输出进行中的场景
- **When** 大模型流式输出完成（收到结束信号）
- **Then** 完整助手回复存入本地缓存，会话列表新增一条会话项，标题取首条消息前 20 字符（超出省略号），输入框恢复可用，"停止生成"按钮隐藏

#### AC-004：多轮对话上下文连续

- **Given** 用户在已有会话继续对话（后端会话未超时）
- **When** 用户输入新消息发送
- **Then** 前端携带当前 sessionId 调用流式接口，大模型基于历史上下文回复，新消息对（用户消息 + 助手回复）追加到本地缓存当前会话的消息列表

#### AC-005：切换会话加载历史纪录

- **Given** 本地缓存存在多个会话纪录
- **When** 用户点击左侧会话列表某个会话
- **Then** 右侧对话框加载该会话所有历史消息（时间正序），滚动到最新消息，输入框聚焦可用

#### AC-006：会话标题自动生成

- **Given** 用户新建会话并发送首条消息
- **When** 流式完成，会话纪录存入本地缓存
- **Then** 会话列表标题显示为首条消息前 20 字符（不足则取全部），超出部分以省略号显示

#### AC-007：重命名会话标题

- **Given** 会话列表存在某个会话
- **When** 用户点击重命名并输入新标题确认
- **Then** 该会话标题更新为新标题，本地缓存同步更新，新标题不超过 50 字符

#### AC-008：删除单个会话

- **Given** 会话列表存在某个会话
- **When** 用户点击删除并确认
- **Then** 该会话从本地缓存移除，会话列表不再显示；若删除的是当前展示会话，右侧切换到新建空会话

#### AC-009：清空全部会话

- **Given** 本地缓存存在多个会话纪录
- **When** 用户点击"清空全部"并二次确认
- **Then** 所有会话纪录被清空，左侧会话列表为空并显示引导提示，右侧切换到新建空会话

### B. 边界/异常场景

#### AC-010：后端会话超时透明续聊

- **Given** 用户在旧会话继续对话，该会话在后端已超 30 分钟被清理
- **When** 用户发送消息，后端返回新 sessionId
- **Then** 前端将后续消息关联到新 sessionId，本地历史纪录仍连续展示在当前会话窗口，用户无感知会话切换；Agent 实际不包含旧上下文（按新会话处理）

#### AC-011：停止生成保留已接收内容

- **Given** 流式输出进行中
- **When** 用户点击"停止生成"按钮
- **Then** 流式中断，已接收的部分内容作为助手回复保留在对话框并存入本地缓存，输入框恢复可用，"停止生成"按钮隐藏

#### AC-012：流式过程网络断开

- **Given** 流式输出进行中
- **When** 网络连接中断
- **Then** 流式中断，已接收的部分内容保留在对话框，显示"网络中断，回复不完整"提示，不完整回复仍存入本地缓存并标记为不完整，输入框恢复可用

#### AC-013：后端服务不可用

- **Given** 后端服务未启动或 API Key 无效
- **When** 用户发送消息
- **Then** 前端显示"服务暂时不可用，请稍后重试"错误提示，消息不存入本地缓存，输入框恢复可用

#### AC-014：空消息拦截

- **Given** 输入框为空或仅含空白字符
- **When** 用户点击发送
- **Then** 不发送请求，不清空输入框，显示"请输入消息内容"提示

#### AC-015：超长消息拦截

- **Given** 用户输入消息超过 4000 字符
- **When** 用户点击发送
- **Then** 不发送请求，显示"消息长度不能超过 4000 字符"提示

#### AC-016：本地缓存容量溢出自动淘汰

- **Given** 本地缓存会话数量已达 50 个上限
- **When** 用户新建会话并完成首次对话
- **Then** 自动删除最旧（最后活跃时间最早）会话，保证当前新建会话成功存入，用户无感知

#### AC-017：重复点击发送防护

- **Given** 流式输出进行中（输入框已禁用）
- **When** 用户尝试点击发送或再次输入
- **Then** 输入框保持禁用状态，不触发新的发送请求

### C. 业务规则

#### AC-018：会话列表排序规则

- **Given** 本地缓存存在多个会话
- **When** 展示会话列表
- **Then** 按最后活跃时间倒序排列（最近使用在最上方），新建会话出现在列表顶部

#### AC-019：会话纪录持久化

- **Given** 用户关闭浏览器后重新打开页面
- **When** 页面加载
- **Then** 从本地缓存读取所有会话纪录并显示在会话列表，历史消息完整可查看

#### AC-020：流式输出逐字显示

- **Given** 大模型正在流式生成回复
- **When** 每收到一个文本片段
- **Then** 对话框实时追加显示该片段，自动滚动到底部，用户可见逐字生成过程

## 4. 功能范围

### 4.1 本次范围

| 能力项 | 说明 |
|--------|------|
| 前端模块新建 | 左右分栏布局：左侧会话列表 + 顶部"新建会话"按钮，右侧对话框 |
| 对话框对话 | 用户输入消息，调用后端流式接口，大模型流式输出 |
| 流式输出（SSE 真流式） | 后端新增 SSE 流式接口，前端逐字实时显示（需后端配合） |
| 本地缓存会话纪录 | 使用浏览器 localStorage 存储完整会话信息（消息 + 元数据） |
| 会话列表管理 | 查看 / 切换 / 删除单个 / 清空全部 / 重命名 |
| 会话标题自动生成 | 首条消息前 20 字符截取（超出省略号） |
| 流式中断 | "停止生成"按钮，已接收内容保留并存入缓存 |
| 透明续聊 | 后端会话超时返回新 sessionId，前端无感切换、本地历史连续展示 |
| 缓存容量溢出处理 | 自动淘汰最旧会话，保留最近 50 个 |
| 会话纪录持久化 | 页面刷新/关闭浏览器后重新打开，历史会话完整可查看 |

### 4.2 不在本次范围

| 排除项 | 原因 |
|--------|------|
| 多 Agent 协作（MULTI 模式） | 后端能力规划中，第一版仅支持 SINGLE |
| 工作流编排（WORKFLOW 模式） | 后端能力规划中 |
| RAG 知识库问答 | 后端能力规划中 |
| MCP 协议互通 | 后端能力规划中 |
| 用户登录/权限体系 | 项目非目标（见 SDD-工程业务背景文档 1.2 节） |
| 会话分享/导出 | 非第一版核心诉求 |
| 消息编辑/重新生成 | 非第一版核心诉求 |
| 多设备会话同步 | 本地缓存仅限当前浏览器，跨设备同步需后端账号体系 |
| 暗黑模式/主题切换 | 非功能性优先级 |
| 移动端适配 | 第一版聚焦桌面端 |
| 工具调用过程可视化（toolCalls） | 第一版不展示工具调用细节，仅展示最终回复 |
| Token 用量统计展示 | 第一版不展示 Token 消耗 |
| 多语言切换 | 第一版仅中文 |

## 6. 依赖与约束

### 6.1 后端依赖

| 依赖项 | 说明 | 约束编号 |
|--------|------|---------|
| SSE 流式对话接口 | 后端需新增流式接口，基于 LangChain4j StreamingChatModel 实现 | TC-LC4J-007 |
| 会话管理接口 | 复用现有 `POST /api/agent/session`、`GET /api/agent/session/{sessionId}` | BR-WEB-002 |

### 6.2 业务约束

| 约束编号 | 描述 | 级别 |

| BR-MEM-002 | 后端会话超时默认 30 分钟，每 5 分钟扫描清理 | ⚪ 可覆盖 |

| BR-WEB-002 | API 路径前缀统一 `/api/agent/` | 🔴 强制 |
