# 功能变更记录: 前端对话模块 - CR-001

## 0. 变更概览 (Change Overview)

*   **变更标题**: 深度思考推理过程展示 + Markdown 渲染优化
*   **变更类型**: 扩展 (Extension)
*   **变更原因**: 用户希望模型执行过程先推理后执行，且在页面上看到推理过程；现有纯文本展示需优化为 Markdown 渲染
*   **发起日期**: 2026-07-21
*   **开发方法**: TDD（测试驱动开发）- 每个任务按 Red-Green-Refactor 循环执行
*   **关联功能**: 前端对话模块
*   **关联文档**:
    -   需求文档: `features/20260720_前端对话模块/前端对话模块.md`
    -   技术方案: `features/20260720_前端对话模块/前端对话模块_技术方案.md`
    -   任务规划: `features/20260720_前端对话模块/前端对话模块_任务规划.md`

> **变更边界说明**: 本次变更为增量扩展，不破坏已有功能。原 `chatStream` 路径保留，新增 `chatThinkingStream` 并行路径；localStorage 旧数据向前兼容（`reasoning` 为空字符串）；SSE 协议向前兼容（旧前端不识别 reasoning 事件会忽略）。

## 2. 需求变更详情 (Requirements Delta)

> 仅记录本次变更涉及的需求变化，已有需求不重复列出

### 2.1 新增/修改的用户故事

- **US-CR001-01**: 作为学习者，我希望在对话中开启深度思考模式，看到模型的推理过程，以便理解 Agent 的"先推理后执行"机制
    - 关联验收标准：AC-021、AC-022、AC-024
- **US-CR001-02**: 作为学习者，我希望助手回复以 Markdown 格式渲染（代码块、列表、表格），以便更清晰地阅读结构化内容
    - 关联验收标准：AC-023

### 2.2 新增/修改的验收标准

#### 正常流程 (Happy Path)

- **AC-021**: 深度思考开关切换
    - Given: 用户在对话页面输入框旁可见"深度思考"开关按钮
    - When: 用户点击开关切换开启/关闭状态
    - Then: 开关状态视觉反馈即时（开启时高亮），下次发送消息时携带对应的 `enableThinking` 参数；开关状态在当前会话内保持，切换会话时不影响其他会话

- **AC-022**: 推理过程流式展示
    - Given: 用户开启"深度思考"开关并发送消息
    - When: 后端流式返回推理内容（reasoning 事件）
    - Then: 助手消息上方显示可折叠的"思考中..."区块，推理内容逐字追加到该区块；推理完成后区块标题变为"已思考 X 秒"并可点击展开/收起；参考主流 AI Chat（如 DeepSeek/ChatGPT）交互习惯

- **AC-023**: 助手消息 Markdown 渲染
    - Given: 助手消息内容包含 Markdown 语法（代码块、列表、表格、加粗、链接等）
    - When: 消息渲染展示
    - Then: 助手正式回复按 Markdown 格式渲染（代码块等宽字体 + 语法高亮背景、列表缩进、表格边框等）；用户消息保持纯文本不渲染；渲染需做 XSS 防护（脚本标签转义）

#### 业务规则 (Business Rules)

- **AC-024**: 推理过程持久化
    - Given: 一条开启深度思考的助手消息已完成（status: complete）
    - When: 消息存入本地缓存
    - Then: 推理内容随消息一起持久化到 localStorage（Message.reasoning 字段）；用户切换会话或刷新页面回看历史时，推理区块仍可展开查看；关闭深度思考开关的消息 reasoning 字段为空字符串

#### 修改的验收标准

- **AC-003** (修改): 流式完成后保存会话纪录
    - Given: 流式输出进行中的场景
    - When: 大模型流式输出完成（收到结束信号）
    - Then: 完整助手回复存入本地缓存（**含推理内容与正式回复两部分，CR-001 扩展**），会话列表新增一条会话项，标题取首条消息前 20 字符（超出省略号），输入框恢复可用，"停止生成"按钮隐藏

- **AC-020** (修改): 流式输出逐字显示
    - Given: 大模型正在流式生成回复
    - When: 每收到一个文本片段
    - Then: 对话框实时追加显示该片段，自动滚动到底部，用户可见逐字生成过程；**当开启深度思考时，推理片段与正式回复片段分别追加到对应区域（CR-001 扩展）**

### 2.3 移除的内容（如有）

无移除内容。本次变更为纯增量扩展。
