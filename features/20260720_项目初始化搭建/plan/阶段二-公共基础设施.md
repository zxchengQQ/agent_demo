## 一、任务概述

实现 `agent-demo-common` 模块，提供全局复用的公共组件，包括统一返回结果、业务异常体系、常量类、枚举与工具类。本模块是所有业务模块的基础依赖，接口设计需稳定。

## 二、依赖关系

### 2.1 前置依赖
- **阶段一（工程骨架）**：需要 common 模块的 pom.xml 与包结构已建立

### 2.2 被依赖（下游影响）
- **阶段三（llm）**：使用 ErrorCode、JsonUtils
- **阶段四（tools）**：使用 ErrorCode
- **阶段五（memory）**：使用 enums、JsonUtils
- **阶段六（agent）**：使用 Result、ErrorCode、enums
- **阶段七（web）**：使用 Result（所有 Controller 返回）、BusinessException、GlobalExceptionHandler
- **阶段八（bootstrap）**：使用常量类
- 若本阶段的 Result/ErrorCode 接口变更，需同步评估所有调用方

## 四、子任务详情

### 4.1 任务 2.1：统一返回结果

#### 子任务 2.1.1：Result<T>
- **目标**：统一的 API 返回结果封装
- **字段设计**：
  - `boolean success`：是否成功
  - `int code`：状态码
  - `String message`：提示信息
  - `T data`：业务数据
  - `String traceId`：链路追踪 ID
- **静态工厂方法**：
  - `Result.success(T data)`
  - `Result.success(T data, String message)`
  - `Result.error(ErrorCode errorCode)`
  - `Result.error(int code, String message)`
- **调用方**：web 层所有 Controller

#### 子任务 2.1.2：PageResult<T>
- **目标**：分页查询返回结果
- **字段设计**：在 Result 基础上增加 `long total`、`int page`、`int size`
- **调用方**：web 层分页接口（后续 RAG 知识库列表等）

### 4.2 任务 2.2：业务异常体系

#### 子任务 2.2.1：ErrorCode 枚举
- **目标**：统一业务错误码定义
- **设计原则**：禁止硬编码状态码，全部使用 ErrorCode 常量
- **枚举项**：
  - `SUCCESS(200, "成功")`
  - `PARAM_INVALID(400, "参数无效")`
  - `UNAUTHORIZED(401, "未授权")`
  - `LLM_CALL_FAILED(5001, "LLM 调用失败")`
  - `LLM_TIMEOUT(5002, "LLM 调用超时")`
  - `TOOL_EXECUTION_FAILED(5003, "工具执行失败")`
  - `MEMORY_NOT_FOUND(5004, "会话记忆不存在")`
  - `RAG_RETRIEVE_FAILED(5005, "知识检索失败")`
  - `MCP_CONNECTION_FAILED(5006, "MCP 连接失败")`
  - `SYSTEM_ERROR(5000, "系统异常")`
- **字段**：`int code`、`String message`

#### 子任务 2.2.2：BusinessException
- **目标**：业务异常基类
- **设计**：
  - 继承 RuntimeException
  - 字段：`ErrorCode errorCode`、`String detail`（补充信息）
  - 构造方法：`BusinessException(ErrorCode)`、`BusinessException(ErrorCode, String)`、`BusinessException(ErrorCode, Throwable)`
- **调用方**：所有业务模块抛出异常时使用
- **禁止**：禁止以 null 作为 errorCode 参数传递

### 4.3 任务 2.3：常量类

#### 子任务 2.3.1：ModelConstants
- **目标**：集中管理模型相关常量，禁止硬编码模型名
- **常量**：
  - `MODEL_DOUBAO_SEED_2_CODE = "doubao-seed-2.0-code"`
  - `MODEL_DOUBAO_SEED_2_PRO = "doubao-seed-2.0-pro"`
  - `MODEL_DOUBAO_SEED_2_LITE = "doubao-seed-2.0-lite"`
  - `MODEL_MINIMAX_M27 = "minimax-m2.7"`
  - `MODEL_GLM_52 = "glm-5.2"`
  - `MODEL_KIMI_K27_CODE = "kimi-k2.7-code"`
  - `MODEL_DEEPSEEK_V4_PRO = "deepseek-v4-pro"`
  - `MODEL_ARK_CODE_LATEST = "ark-code-latest"`
  - `MODEL_DOUBAO_EMBEDDING = "doubao-embedding-large-text-240915"`
  - `ARK_BASE_URL = "https://ark.cn-beijing.volces.com/api/coding/v3"`
- **调用方**：llm 层、bootstrap 配置

#### 子任务 2.3.2：StatusCode
- **目标**：HTTP 状态码常量（与 ErrorCode 区分，ErrorCode 是业务码）
- **调用方**：web 层

### 4.4 任务 2.4：枚举类

#### 子任务 2.4.1：AgentType
- **目标**：Agent 类型枚举
- **枚举项**：`SINGLE`（单 Agent）、`MULTI`（多 Agent）、`WORKFLOW`（工作流 Agent）
- **字段**：`String code`、`String desc`
- **调用方**：agent 层、web 层

#### 子任务 2.4.2：MessageType
- **目标**：消息类型枚举
- **枚举项**：`SYSTEM`、`USER`、`ASSISTANT`、`TOOL`
- **调用方**：memory 层、agent 层

#### 子任务 2.4.3：MemoryType
- **目标**：记忆类型枚举
- **枚举项**：`SHORT_TERM`（短期）、`MID_TERM`（中期摘要）、`LONG_TERM`（长期向量）
- **调用方**：memory 层

### 4.5 任务 2.5：工具类

#### 子任务 2.5.1：JsonUtils
- **目标**：JSON 序列化/反序列化工具
- **实现**：基于 Jackson（Spring Boot 自带）
- **方法**：`toJson(Object)`、`fromJson(String, Class<T>)`、`fromJson(String, TypeReference<T>)`
- **调用方**：llm 层（解析 LLM 响应）、memory 层

#### 子任务 2.5.2：DateUtils
- **目标**：日期时间工具
- **方法**：`now()`、`format(LocalDateTime, String)`、`parse(String, String)`
- **调用方**：日志、会话管理

### 4.6 任务 2.6：验证
- **目标**：编写单元测试验证公共组件
- **测试范围**：
  - Result 构造与静态工厂
  - BusinessException 抛出与捕获
  - JsonUtils 序列化/反序列化
- **验证命令**：`mvn test -pl agent-demo-common`

## 五、关键接口设计

### 5.1 Result<T> 接口签名（影响 web 层全部 Controller）
```java
public class Result<T> {
    public static <T> Result<T> success(T data);
    public static <T> Result<T> error(ErrorCode errorCode);
    public static <T> Result<T> error(int code, String message);
}
```
**调用方枚举**：web 层所有 Controller 的返回类型

### 5.2 BusinessException（影响所有业务模块）
```java
public class BusinessException extends RuntimeException {
    public BusinessException(ErrorCode errorCode);
    public BusinessException(ErrorCode errorCode, String detail);
}
```
**调用方枚举**：llm/tools/memory/rag/mcp/agent 模块的异常抛出

## 七、风险与注意事项

1. **Result 字段稳定性**：Result 是全局返回结构，字段一旦确定应避免频繁变更，否则影响所有 Controller
2. **ErrorCode 扩展性**：预留 5xxx 段给业务错误，2xx/4xx/5xx 给 HTTP 标准码，新增错误码统一在 ErrorCode 添加
3. **禁止 null 参数**：BusinessException 禁止以 null 作为 errorCode，需通过重载方法处理不同场景
4. **常量类禁止硬编码**：所有模型名、状态码必须通过常量类引用，禁止在调用方写魔法字符串
5. **工具类无状态**：JsonUtils/DateUtils 全部为静态方法，无实例状态，线程安全
