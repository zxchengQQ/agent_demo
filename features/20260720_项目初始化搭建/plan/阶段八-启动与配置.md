## 一、任务概述

实现 `agent-demo-bootstrap` 模块，提供 Spring Boot 应用启动入口与多环境配置。包含主启动类、application.yml 主配置、开发/生产环境配置、提示词模板资源、日志配置。本模块聚合所有业务模块，是工程可运行的最后一环。

## 四、子任务详情

### 4.1 任务 8.1：主启动类 AgentDemoApplication

- **目标**：Spring Boot 应用入口
- **实现要点**：
  ```java
  @SpringBootApplication(scanBasePackages = "com.agentdemo")
  @EnableScheduling              // 启用定时任务（会话清理）
  @EnableConfigurationProperties // 启用配置属性绑定
  public class AgentDemoApplication {
      public static void main(String[] args) {
          SpringApplication.run(AgentDemoApplication.class, args);
      }
  }
  ```
- **扫描包配置**：`com.agentdemo` 扫描所有子模块的 Bean
- **启动验证**：应用启动后打印 Banner 与关键配置信息

### 4.2 任务 8.2：主配置文件 application.yml

- **目标**：通用配置，所有环境共享
- **配置内容**：
  ```yaml
  spring:
    application:
      name: agent-demo
    profiles:
      active: dev  # 默认开发环境
    jackson:
      default-property-inclusion: non_null
      serialization:
        write-dates-as-timestamps: false

  server:
    port: 8080
    servlet:
      context-path: /
    tomcat:
      connection-timeout: 300000  # SSE 流式接口超时 5 分钟

  # 火山引擎配置（阶段三定义）
  ark:
    coding-plan:
      base-url: https://ark.cn-beijing.volces.com/api/coding/v3
      api-key: ${ARK_API_KEY}
      default-model: doubao-seed-2.0-code
      models:
        chat: doubao-seed-2.0-pro
        code: doubao-seed-2.0-code
        lite: doubao-seed-2.0-lite
      timeout: 60s
      max-retries: 3
      temperature: 0.7

  # Agent 配置（阶段六定义）
  agent:
    max-iterations: 10
    chat-memory-window-size: 20
    enable-logging: true

  # 会话配置
  session:
    timeout-minutes: 30

  # Springdoc Swagger
  springdoc:
    api-docs:
      path: /v3/api-docs
    swagger-ui:
      path: /swagger-ui.html
      enabled: true
  ```
- **安全要求**：
  - `api-key` 必须使用 `${ARK_API_KEY}` 占位，从环境变量注入
  - 禁止在配置文件中硬编码 API Key

### 4.3 任务 8.3：多环境配置

#### 子任务 8.3.1：application-dev.yml
- **目标**：开发环境配置
- **特点**：
  - 使用 Lite 模型（节省套餐额度）：`default-model: doubao-seed-2.0-lite`
  - 详细日志：`logging.level.com.agentdemo: DEBUG`
  - 启用 Swagger UI
  - H2 内存数据库（开发阶段）
  - 热重载（spring-boot-devtools）

#### 子任务 8.3.2：application-prod.yml
- **目标**：生产环境配置
- **特点**：
  - 使用 Pro 模型：`default-model: doubao-seed-2.0-pro`
  - 简洁日志：`logging.level.com.agentdemo: INFO`
  - 关闭 Swagger UI（或加密访问）
  - MySQL 数据库
  - 关闭 devtools

### 4.4 任务 8.4：提示词模板

#### 子任务 8.4.1：default.txt
- **目标**：默认系统提示词
- **内容**：通用助手角色定义，说明 Agent 能力边界
- **调用方**：SimpleAgent 的 systemMessageProvider

#### 子任务 8.4.2：code-assistant.txt
- **目标**：编程助手系统提示词
- **内容**：资深 Java 工程师角色，擅长代码生成、审查、调试
- **调用方**：CodeAssistantAgent

#### 子任务 8.4.3：general-assistant.txt
- **目标**：通用助手系统提示词
- **内容**：全能助手角色，可调用多种工具回答问题
- **调用方**：GeneralAssistantAgent
- **存放路径**：`agent-demo-bootstrap/src/main/resources/prompts/`

### 4.5 任务 8.5：日志配置 logback-spring.xml

- **目标**：结构化日志，含 traceId
- **配置要点**：
  - 日志格式：`%d{yyyy-MM-dd HH:mm:ss} [%thread] [%X{traceId}] %-5level %logger{36} - %msg%n`
  - 输出到控制台 + 文件
  - 文件滚动：按天切割，保留 7 天
  - 日志级别：com.agentdemo 包 DEBUG（dev）/ INFO（prod）
  - 特殊日志：LLM 调用日志单独输出到 `logs/llm/` 目录
- **traceId**：通过 MDC 传递，由 web 层 TraceIdInterceptor 生成

### 4.6 任务 8.6：启动验证

- **目标**：验证应用可正常启动
- **验证内容**：
  - 执行 `mvn spring-boot:run -pl agent-demo-bootstrap`
  - 检查启动日志：
    - `Started AgentDemoApplication in X seconds`
    - ArkProperties 加载成功（apiKey 非空）
    - ToolRegistry 注册工具数量 ≥ 4
    - ModelFactory 初始化成功
  - 检查端口监听：8080 可访问
  - 检查 Swagger UI：`http://localhost:8080/swagger-ui.html` 可访问
- **前置条件**：环境变量 `ARK_API_KEY` 已配置
- **验证命令**：`mvn spring-boot:run -pl agent-demo-bootstrap`

## 七、风险与注意事项

1. **API Key 安全**：`ARK_API_KEY` 必须通过环境变量注入，禁止写入 application.yml 或代码，禁止提交到 Git
2. **启动顺序**：Spring Bean 初始化顺序需正确，ToolRegistry 必须在 Agent 初始化前完成扫描
3. **扫描包范围**：`scanBasePackages = "com.agentdemo"` 确保扫描所有子模块，避免遗漏 Bean
4. **配置文件编码**：application.yml 含中文提示词时，需确保 UTF-8 编码
5. **端口冲突**：8080 端口可能被占用，提供 `server.port` 配置可改
6. **日志路径**：Windows 与 Linux 路径分隔符不同，logback 配置使用相对路径 `./logs/`
7. **Profile 激活**：默认 dev 环境，生产部署需通过 `--spring.profiles.active=prod` 激活
8. **devtools 排除**：生产打包时排除 devtools，避免热重载影响生产稳定性
9. **Banner 配置**：可选自定义 banner.txt，提升项目识别度
