# 可观测性模块 业务说明书

> **文档版本**: v1.0 | **基线日期**: 2026-08-31
> **覆盖范围**: 基础特性（20260829 langsmith-observability Task-01~14）+ CR-001 观察空间扩展（Task-15~25）

## 1. 模块概述

* **工程模块**: `agent-demo-observability`（旁路采集子系统，非对话型/任务型 Agent，不与终端用户交互）
* **定位**: LangSmith 可观测性接入——挂载在对话/工作流/检索等链路两侧的旁路采集器，经 OpenTelemetry 标准将事件构建为 span，经 OTLP HTTP 上报 LangSmith 云，实现 Agent 执行链路可视化、Token 用量统计、真实模型行为评估最小闭环。全程对终端用户零感知、对主流程零影响。
* **接入方式**: Spring 条件装配——`langsmith.enabled=true` 且环境变量 `LANGSMITH_API_KEY` 非空时装配 OtlpTraceCollector（OTLP 上报）；否则装配 NoopTraceCollector（零初始化零外联，AC-S02）。
* **采集范围**: 基础（LLM 调用 + 工具调用，20260829 交付）+ 五域事件扩展（RAG 检索 / 记忆压缩 / 工作流编排 / MCP 协议层 / Skill 激活，CR-001 交付）。
* **风险归类**: L4 类不可回滚风险（数据出境 LangSmith 云），以三重护栏对冲：默认关闭（AC-S02）+ 基础脱敏（AC-S01/S06）+ 静默降级（AC-S04/E05）。

## 2. 用户角色与权限

| 角色 | 职责 | 权限 |
|------|------|------|
| 开发者 | 调试 Agent 行为、定位工具选择问题 | LangSmith 平台账号（应用级 Key） |

| 运维者 | Token 消耗监控、配置 Key | 环境变量注入（部署时一次性授权） |

* **身份模型**: 应用级 Key（非用户级），演示项目单租户无用户鉴权体系。

## 3. 业务功能点

### 3.1 采集接口与条件装配（TraceCollector / Noop / Otlp）
`TraceCollector` 为埋点统一上报入口（8 类事件：LLM / 工具 / RAG 检索 / 记忆压缩 / 工作流 / 工作流步骤 / MCP / Skill 激活）；`NoopTraceCollector` 默认空实现（未启用零开销）；`OtlpTraceCollector` 构建 OTel span（GenAI semconv 属性）并作为脱敏单一出口。

### 3.2 LLM + 工具采集（基础特性）
`ModelFactory` 挂 `TraceChatModelListener`（OpenAI 系）+ `TracingThinkingStreamingChatModel` 装饰器（Thinking 系，取 onComplete 真实 TokenUsage）；`ToolExecutor.execute` 工具统一收口埋点；`AgentController` 异步边界捕获 traceId/sessionId。

> **2026-08-31 CR-002 审查补链**：AiServices 反射路径（SimpleAgent 同步路径内置 ReAct）此前绕过 ToolExecutor 无工具采集（技术方案决策 3 既有边界）。现经 `SimpleAgent.afterToolExecution` → `ToolExecutor.recordToolExecution(ToolExecution)` 统一采集（含工具结果），**生产同步 /chat 路径工具 span 从缺失变为完整**（AC-N01/N04 净提升），同时为评估 harness 提供工具轨迹证据。

### 3.3 五域事件采集（CR-001）
| 域 | 埋点收口 | 说明 |
|----|---------|------|
| RAG 检索 | `KnowledgeRetrieverTool.searchByKbId` | 动态 Tool 唯一收口（对话+工作流全覆盖） |
| 记忆压缩 | `CompressingChatMemory` 回调注入 | 闭包捕获 sessionId，成功/降级双路径 |
| 工作流编排 | `WorkflowExecutionService` 三入口 + `AbstractExecutionStrategy.executeOrSkip` | 工作流级+步骤级双层 span，executionId 聚合，并行线程池传播 |
| MCP 协议层 | `McpToolExecutor.execute` | 与工具 span 双层平级（协议层原始参数+耗时） |
| Skill 激活 | `SkillSessionManager` | 激活成功/被拒/手动批量逐项留痕 |

### 3.4 脱敏与截断（SensitiveDataMasker）
密钥模式正则（`sk-` 前缀、`Bearer` 令牌）+ 装配时收集环境密钥值精确替换 + 超长截断（max-field-chars + `[TRUNCATED]`）；masker 自身异常保守整字段 `[MASKED]`。所有出境属性统一经此出口，无绕行（AC-S01/S06）。

### 3.5 上下文传播（TraceContextHolder）
ThreadLocal 持有 traceId/sessionId（无显式上下文回退 MDC traceId）；对话路径由 Controller 异步边界注入；工作流路径由 `WorkflowExecutionService` 三入口注入（executionId 作 thread 聚合键）+ 并行线程 Runnable 包装传播（AC-M03）。

> **2026-09-01 BUG 修复（HITL 多轮 trace 续接）**：HITL 暂停/恢复跨 HTTP 请求原先产生独立 trace（LangSmith 呈现一条完整链路 + 多条独立人机交互短链路）。现暂停点（askUser/tool_confirm/工作流 WAITING_USER）经 `TraceCollector.markHITLPause(key)` 保存根 span 上下文，恢复轮经 `resumeRequest(key)` 以远程父上下文续接同一 traceId——单任务多轮人机交互呈现一条完整链路（详见 `docs/BUG修复文档/20260901-1039-HITL多轮人机交互LangSmithtrace碎片化.md`）。

### 3.6 OTLP 上报
OTLP HTTP（protobuf）+ `x-api-key` 认证头 + `Langsmith-Project` header；`endpoint` 必须为完整 URL（含 `/v1/traces` 信号路径，OTel Java exporter 直接使用不追加）；project 归属经 resource service.name + header 双写（默认 `agent-demo`）。

## 4. 业务规则清单

1. **默认关闭零外联**：未配置 `LANGSMITH_API_KEY` 或 enabled=false → Noop 装配，零网络零初始化（AC-S02）。
2. **脱敏单一出口**：所有出境属性统一经 `SensitiveDataMasker`，无绕行路径（AC-S01/S06）。
3. **静默降级**：埋点/上报/脱敏任何异常仅 WARN 降级，不影响对话主流程（AC-S04/E01/E05）。
4. **Key 不泄漏**：Key 仅存在于环境变量，不出现在日志/前端/SSE/trace（AC-S03）。
5. **endpoint 完整 URL**：OTel Java exporter 直接使用 endpoint 不追加路径，缺 `/v1/traces` 会 POST 到错误路径致 LangSmith 404（2026-08-31 修复）。
6. **project 归属**：resource service.name + `Langsmith-Project` header 双写，trace 落 `agent-demo` project（防 unknown_service:java）。
7. **全量采集不采样**：无采样率控制；无五域独立开关（`langsmith.enabled` 单一总开关）。
8. **工作流 thread 聚合**：以 executionId 为聚合键，并行步骤按执行 ID 关联而非线程（AC-M03）。

* **REST API**: 无（旁路采集子系统，不暴露 HTTP 端点）。
* **配置项**（application.yml `langsmith.*`）:

| 配置 | 默认值 | 说明 |

| `langsmith.enabled` | false | 总开关（默认关，AC-S02） |

| `langsmith.project` | `agent-demo` | LangSmith project 归属 |
| `langsmith.max-field-chars` | 4000 | 单字段截断阈值（AC-E02） |
| `langsmith.export-timeout-ms` / `export-interval-ms` | 5000 | 导出超时/间隔 |
| `langsmith.max-queue-size` | 2048 | BatchSpanProcessor 队列上限 |
