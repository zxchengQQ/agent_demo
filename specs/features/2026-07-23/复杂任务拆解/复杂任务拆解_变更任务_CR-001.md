# 功能变更记录: 复杂任务拆解 - CR-001

## 0. 变更概览 (Change Overview)

*   **变更标题**: 子任务执行中实时展示 ReAct 过程
*   **变更类型**: 微调 (Tweak)
*   **变更原因**: 用户希望在使用任务拆解模式时，页面能实时展示每个子任务的 ReAct 过程（Thought/Action/Observation），而非等到子任务完成后才能展开查看。当前实现中 ReAct 数据已全链路实时推送，但前端 MessageItem.vue 仅允许 `completed` 状态的子任务展开，导致执行中无法查看实时过程。
*   **发起日期**: 2026-07-24
*   **开发方法**: TDD（测试驱动开发）- 每个任务按 Red-Green-Refactor 循环执行
*   **关联功能**: 复杂任务拆解 (CR-002)
*   **关联文档**:
    -   需求文档: `specs/features/2026-07-23/复杂任务拆解/复杂任务拆解.md`
    -   技术方案: `specs/features/2026-07-23/复杂任务拆解/复杂任务拆解_技术方案.md`
    -   任务规划: `specs/features/2026-07-23/复杂任务拆解/复杂任务拆解_任务规划.md`

## 2. 需求变更详情 (Requirements Delta)

> 仅记录本次变更涉及的需求变化，已有需求不重复列出

### 2.1 修改的用户故事

- **US-002**（修改）: 作为 **学习者**，我想要 **在任务列表中展开查看每个子任务的执行详情（含执行中实时 ReAct 过程）**，以便 **理解 Agent 在每个步骤中做了什么**。
    - 关联验收标准：AC-005, AC-016, AC-017

### 2.2 修改/新增的验收标准

#### 正常流程 (Happy Path)

- **AC-005**（修改）: 展开查看子任务详情（执行中/已完成）
    - Given: 任务列表中某子任务处于"执行中"或"已完成"状态
    - When: 用户点击该子任务条目（执行中状态下自动展开）
    - Then: 展开显示该子任务的 ReAct 过程（Thought/Action/Observation）和结果摘要；执行中状态下 ReAct 步骤实时更新

- **AC-017**（新增）: 执行中实时展示 ReAct 过程
    - Given: 任务列表中某子任务状态从"待执行"变为"执行中"
    - When: 子任务开始执行，后端推送 task_thought/task_action/task_observation 事件
    - Then: 该子任务自动展开，ReAct 步骤（Thought/Action/Observation）实时出现在详情区域，用户无需手动点击即可观察执行过程

## 3. 技术变更详情 (Technical Delta)

> 仅记录本次变更涉及的技术变化

### 3.3 组件变更

| 操作 | 组件 | 说明 |
| :--- | :--- | :--- |
| 修改 | `MessageItem.vue` | 3 处修改：(1) `toggleSubTask` 状态判断扩展；(2) v-if 条件扩展；(3) 新增 watcher 自动展开 |

**具体修改点**:

**修改点 1 - `toggleSubTask` 函数（约 L117-L127）**:

```typescript
// 修改前：
function toggleSubTask(index: number) {
  const subTask = props.message.subTasks?.find((st) => st.index === index);
  if (!subTask || subTask.status !== 'completed') return;  // 仅 completed 可展开
  // ...
}

// 修改后：
function toggleSubTask(index: number) {
  const subTask = props.message.subTasks?.find((st) => st.index === index);
  // 业务含义：in-progress 和 completed 状态的子任务可展开（CR-001 变更）
  if (!subTask || (subTask.status !== 'completed' && subTask.status !== 'in-progress')) return;
  // ...
}
```

**修改点 2 - v-if 条件（约 L252）**:

```html
<!-- 修改前： -->
<div v-if="expandedSubTasks.has(subTask.index) && subTask.status === 'completed'"
     class="subtask-detail">

<!-- 修改后： -->
<div v-if="expandedSubTasks.has(subTask.index) && (subTask.status === 'completed' || subTask.status === 'in-progress')"
     class="subtask-detail">
```

**修改点 3 - 新增 watcher（在 expandedSubTasks 定义之后）**:

```typescript
/**
 * 监听子任务状态变化，pending->in-progress 时自动展开（CR-001 新增，AC-017）
 * 业务含义：子任务开始执行时自动展开详情，用户无需手动点击即可看到实时 ReAct 过程
 */
watch(
  () => props.message.subTasks?.map((st) => `${st.index}:${st.status}`).join(','),
  () => {
    if (!props.message.subTasks) return;
    for (const subTask of props.message.subTasks) {
      if (subTask.status === 'in-progress' && !expandedSubTasks.value.has(subTask.index)) {
        expandedSubTasks.value.add(subTask.index);
        expandedSubTasks.value = new Set(expandedSubTasks.value);
      }
    }
  },
);
```

### 3.4 兼容性说明

*   **向前兼容**: 完全兼容。`completed` 状态的展开行为不变，仅扩展了 `in-progress` 状态的展开能力
*   **数据兼容**: 旧消息的 subTasks 无 reactSteps 字段时，展开后仅显示 content（v-if 有空值保护），行为与现有一致
*   **无迁移方案需要**: 纯前端展示逻辑调整，不涉及数据格式变化
