# 功能需求说明书 (Feature Requirements Document)

## 1. 背景与价值 (Context & Value)

*   **背景**: agent-demo 项目已实现单 Agent 对话、工具调用、记忆系统等核心能力，但 Agent 的知识仅限于 LLM 预训练数据，无法回答用户私有知识领域的问题。RAG（检索增强生成）模块通过构建知识库，让 Agent 在回答问题时检索相关文档片段作为上下文，从而实现基于私有知识的准确问答。
*   **目标**: 为 Agent 提供知识库问答能力，用户可上传文档构建知识库，Agent 在对话中自主检索知识库并基于文档内容回答问题。
*   **关联**: KNOWLEDGE_BASE.md 能力矩阵 - RAG 检索（🚧 规划中 -> ✅ 已实现）；错误码区间 5300-5399（RAG 相关）

## 2. 功能范围 (Scope)

### 2.1 本次范围（In Scope）

*   知识库管理：创建知识库、查看知识库列表、删除知识库（级联删除文档和向量数据）
*   文档管理：上传文档（异步处理）、查看文档列表、查询文档处理状态、删除文档
*   文档处理：文档分块、向量化（Embedding）、存入向量数据库（Milvus）
*   检索能力：纯向量语义检索，返回 Top-5 最相关文档片段
*   Agent 集成：RAG 作为 Agent 工具，Agent 自主决定是否检索及检索哪个知识库
*   文档格式：纯文本（.txt）、Markdown（.md）、PDF（.pdf）
*   PDF 表格提取：PDF 文档中的表格内容解析为 Markdown 表格格式，保留行列结构（CR-001 新增）
*   管理接口：REST API（知识库 CRUD + 文档 CRUD + 状态查询）

### 2.2 不在本次范围（Out of Scope）

*   Word（.docx）/ Excel（.xlsx）/ CSV 等 Office 格式 - 后续迭代，需引入 POI 等解析库
*   图片处理（需 OCR 或多模态模型） - 后续迭代，技术栈差异较大
*   视频处理（需音视频转录） - 后续迭代，技术栈差异较大
*   混合检索（向量 + 关键词） - 后续迭代，需引入 Elasticsearch 等全文索引
*   前端知识库管理界面 - 后续迭代，本期仅提供 REST API
*   文档内容权限控制 - 暂不考虑，本项目为学习示例无认证机制
*   知识库重命名 - 后续迭代，本期仅支持创建和删除

## 3. 用户角色 (Actors)

*   **API 调用方**: 通过 REST API 管理知识库和文档（创建知识库、上传文档、查询状态等）
*   **对话用户**: 通过现有对话界面与 Agent 交互，Agent 自主检索知识库回答问题
*   **Agent**: 自主判断是否需要检索知识库、选择检索哪个知识库、基于检索结果组织回答

## 4. 用户故事 (User Stories)

*   **US-001**: 作为 **API 调用方**，我想要 **创建和管理多个知识库**，以便 **按主题分类组织不同领域的文档**。
    *   关联验收标准：AC-001, AC-002, AC-009, AC-010, AC-011, AC-021, AC-026

*   **US-002**: 作为 **API 调用方**，我想要 **上传文档到知识库并查询处理状态**，以便 **将私有知识导入系统供 Agent 检索**。
    *   关联验收标准：AC-003, AC-004, AC-005, AC-008, AC-012, AC-013, AC-017, AC-018, AC-019, AC-022, AC-023, AC-025

*   **US-003**: 作为 **对话用户**，我想要 **向 Agent 提问并获得基于知识库的回答**，以便 **获取私有知识领域的准确信息**。
    *   关联验收标准：AC-006, AC-007, AC-014, AC-015, AC-016, AC-020, AC-024, AC-027

## 5. 详细需求与流程 (Detailed Requirements)

### 5.1 核心流程

**流程 A - 知识库管理：**

1. API 调用方提交知识库名称（必填）和描述（可选）创建知识库
2. 系统返回知识库 ID
3. API 调用方可查询知识库列表，了解已有知识库及各库文档数量
4. API 调用方可删除知识库，系统级联删除该库下所有文档记录和向量数据

**流程 B - 文档管理：**

1. API 调用方通过 API 向指定知识库上传文档
2. 系统接收文档文件，校验格式和大小，创建文档记录，状态标记为"待处理"
3. 系统返回文档 ID 和任务 ID
4. 后台异步执行：文档解析 -> 文档分块 -> 向量化（Embedding）-> 存入向量数据库
5. 处理完成后文档状态更新为"已完成"；处理失败状态更新为"失败"并记录原因
6. API 调用方可通过文档 ID 查询处理状态
7. API 调用方可查看知识库下所有文档列表
8. API 调用方可删除文档，系统同步删除文档记录和对应的向量数据

**流程 C - 检索问答：**

1. 对话用户在现有对话界面提问
2. Agent（ReAct 循环）判断是否需要检索知识库
3. 若需要检索：Agent 自主选择目标知识库，调用知识库检索工具
4. 检索工具在指定知识库中执行向量语义检索，返回 Top-5 最相关文档片段
5. Agent 基于检索到的片段内容组织回答
6. 若无需检索：Agent 直接回答，不调用检索工具

### 5.2 交互/界面规则 (UI/UX Rules)

*   本期仅提供 REST API，无前端管理界面
*   知识库检索通过现有 Agent 对话界面触发，用户对话方式不变
*   Agent 是否检索知识库对用户透明，由 Agent 自主决策
*   文档上传后异步处理，API 调用方需轮询状态接口查询处理结果

### 5.3 业务规则 (Business Rules)

*   **BR-RAG-001**: 知识库名称长度 1-50 个字符，仅允许中英文、数字、下划线（_）和连字符（-）
*   **BR-RAG-002**: 知识库名称不允许重复（全局唯一）
*   **BR-RAG-003**: 知识库描述长度不超过 200 个字符
*   **BR-RAG-004**: 单个文档大小不超过 10MB
*   **BR-RAG-005**: 支持的文档格式：txt、md、pdf（第一期）
*   **BR-RAG-006**: 同一知识库下允许同名文档，以文档 ID 区分
*   **BR-RAG-007**: 文档处理采用异步模式，状态流转：待处理 -> 处理中 -> 已完成/失败
*   **BR-RAG-008**: 检索结果最多返回 5 个最相关文档片段，按相似度降序排列
*   **BR-RAG-009**: 删除知识库时级联删除其下所有文档记录和向量数据
*   **BR-RAG-010**: 删除文档时同步删除该文档对应的所有向量数据
*   **BR-RAG-011**: 每个知识库自动注册为独立的 Agent Tool（工具名格式：`knowledgeBase_{kbId}`），Agent 通过选择 Tool 来使用对应知识库，无需传知识库名称参数（CR-003 修改）
*   **BR-RAG-012**: 向量数据库不可用时检索工具返回错误提示，不导致 Agent 对话中断
*   **BR-RAG-013**: PDF 文档解析支持表格结构提取，表格内容转换为 Markdown 格式保留行列关系，无表格区域回退纯文本提取（CR-001 新增）
*   **BR-RAG-018**: 分块数据携带来源元数据（fileName、format、pageNumber/headerText），检索结果中包含来源信息，Agent 回答时可引用文档来源（CR-002 新增）
*   **BR-RAG-019**: 创建知识库时系统自动生成对应的 Tool 实例并注册到 ToolRegistry；删除知识库时自动注销对应 Tool（CR-003 新增）
*   **BR-RAG-020**: 系统启动时自动扫描所有已有知识库，批量生成并注册 Tool，确保重启后工具立即可用（CR-003 新增）

## 6. 验收标准 (Acceptance Criteria)

> **重要**：以下验收标准是后续技术方案、任务规划和 TDD 测试用例的直接依据。每条 AC 必须使用 Given-When-Then 格式，必须可被测试验证。

### 6.1 正常流程 (Happy Path)

- [ ] **AC-001**: 创建知识库
    - Given: 用户想要创建一个新的知识库
    - When: 用户提交知识库名称"产品文档"和可选描述"产品相关技术文档"
    - Then: 系统创建知识库成功，返回知识库 ID，知识库可在列表中查到

- [ ] **AC-002**: 查看知识库列表
    - Given: 系统中已存在多个知识库
    - When: 用户查询知识库列表
    - Then: 系统返回所有知识库的信息，包含 ID、名称、描述、文档数量、创建时间

- [ ] **AC-003**: 上传文档到知识库（异步处理启动）
    - Given: 用户已创建一个知识库，准备上传一个 5MB 的 PDF 文档
    - When: 用户通过 API 上传文档到指定知识库
    - Then: 系统接收文档并返回文档 ID 和任务 ID，文档状态标记为"待处理"

- [ ] **AC-004**: 查询文档处理状态（处理完成）
    - Given: 一个文档正在异步处理中
    - When: 用户查询该文档的处理状态
    - Then: 系统返回文档当前状态（待处理/处理中/已完成/失败），已完成时包含分块数量信息

- [ ] **AC-005**: 查看知识库下的文档列表
    - Given: 一个知识库下已上传多个文档
    - When: 用户查询该知识库的文档列表
    - Then: 系统返回该知识库下所有文档的信息，包含 ID、名称、大小、格式、状态、上传时间

- [ ] **AC-006**: Agent 自主选择知识库 Tool 并检索（CR-003 修改）
    - Given: 系统中有多个知识库，每个知识库已自动注册为独立 Tool（工具名格式：knowledgeBase_{kbId}），用户在对话中提问"产品A的价格是多少"
    - When: Agent 判断需要检索知识库，自主选择"产品文档"对应的 Tool 进行检索
    - Then: Agent 调用该 Tool，工具在对应知识库中执行向量语义检索，返回最相关的文档片段

- [ ] **AC-007**: Agent 基于检索结果回答用户
    - Given: Agent 已从知识库 Tool 检索到相关文档片段
    - When: Agent 基于检索到的片段内容组织回答
    - Then: Agent 返回基于知识库内容的回答，用户获得准确的知识库信息

- [ ] **AC-008**: 删除文档
    - Given: 知识库中有一个已处理完成的文档
    - When: 用户删除该文档
    - Then: 系统删除文档记录和对应的向量数据，文档从知识库文档列表中移除

- [ ] **AC-009**: 删除知识库（级联删除）
    - Given: 一个知识库下有多个文档
    - When: 用户删除该知识库
    - Then: 系统删除知识库记录及其下所有文档记录和全部向量数据

- [x] **AC-028**: PDF 文件包含表格时解析为 Markdown 表格格式（CR-001 新增）
    - Given: 用户上传一个包含表格的 PDF 文件到知识库
    - When: 后台异步处理解析该 PDF 文件
    - Then: 解析结果中包含 Markdown 格式的表格内容，表格的行列结构被保留，Agent 检索时可正确回答表格相关问题

- [x] **AC-031**: 检索结果包含来源元数据（CR-002 新增）
    - Given: 知识库中已上传多个文档（含 PDF 和 Markdown），文档处理已完成
    - When: Agent 调用知识库检索工具，检索到相关文档片段
    - Then: 每个检索结果片段包含来源信息（文件名、格式、页码或章节标题），Agent 回答时可引用文档来源

### 6.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-010**: 知识库命名规则
    - Given: 用户创建知识库
    - When: 用户提交名称为 1-50 个字符的字符串（允许中英文、数字、下划线、连字符）
    - Then: 知识库创建成功

- [ ] **AC-011**: 知识库名称重复
    - Given: 系统中已存在名为"产品文档"的知识库
    - When: 用户再次创建名为"产品文档"的知识库
    - Then: 系统拒绝创建，返回"知识库名称已存在"的提示

- [ ] **AC-012**: 文档大小在限制内
    - Given: 用户准备上传一个 10MB 的文档
    - When: 用户上传该文档
    - Then: 系统接受上传，文档正常进入异步处理流程

- [ ] **AC-013**: 文档超过大小限制
    - Given: 用户准备上传一个 11MB 的文档
    - When: 用户上传该文档
    - Then: 系统拒绝上传，返回"文档大小超过 10MB 限制"的提示

- [ ] **AC-014**: 检索无结果
    - Given: 用户在"产品文档"知识库中提问一个知识库中无相关内容的问题
    - When: Agent 调用检索工具检索该知识库
    - Then: 工具返回"未找到相关文档"的提示，Agent 告知用户知识库中无相关信息

- [ ] **AC-015**: Agent 判断无需检索知识库
    - Given: 用户提问一个与知识库无关的问题（如"现在几点"）
    - When: Agent 判断无需检索知识库
    - Then: Agent 直接回答，不调用知识库检索工具

- [ ] **AC-016**: 空知识库检索
    - Given: 用户创建了一个空知识库（无任何文档）
    - When: Agent 尝试检索该空知识库
    - Then: 工具返回"知识库为空"的提示，Agent 告知用户该知识库暂无内容

- [ ] **AC-017**: 上传不支持的文档格式
    - Given: 用户准备上传一个 .docx 格式的文档
    - When: 用户上传该文档
    - Then: 系统拒绝上传，返回"不支持的文档格式，仅支持 txt、md、pdf"的提示

- [ ] **AC-018**: 文档解析失败
    - Given: 用户上传了一个内容损坏的 PDF 文件
    - When: 后台异步处理尝试解析该文档
    - Then: 文档状态标记为"失败"，记录失败原因"文档解析失败"

- [ ] **AC-019**: 向量化失败
    - Given: 文档解析成功，但向量化过程中 Embedding 服务不可用
    - When: 后台异步处理执行向量化
    - Then: 文档状态标记为"失败"，记录失败原因"向量化失败"

- [ ] **AC-020**: 向量数据库不可用
    - Given: 向量数据库（Milvus）服务不可用
    - When: Agent 调用知识库检索工具
    - Then: 工具返回错误提示，Agent 告知用户"知识库服务暂时不可用"，对话不中断

- [ ] **AC-021**: 删除不存在的知识库
    - Given: 用户尝试删除一个不存在的知识库 ID
    - When: 用户执行删除操作
    - Then: 系统返回"知识库不存在"的提示

- [ ] **AC-022**: 删除不存在的文档
    - Given: 用户尝试删除一个不存在的文档 ID
    - When: 用户执行删除操作
    - Then: 系统返回"文档不存在"的提示

- [ ] **AC-023**: 向不存在的知识库上传文档
    - Given: 用户尝试向一个不存在的知识库 ID 上传文档
    - When: 用户执行上传操作
    - Then: 系统返回"知识库不存在"的提示

- [ ] **AC-024**: 检索时指定不存在的知识库
    - Given: Agent 尝试检索一个不存在的知识库名称
    - When: Agent 调用知识库检索工具
    - Then: 工具返回"知识库不存在"的提示，Agent 告知用户该知识库不存在

- [ ] **AC-025**: 重复上传同名文档
    - Given: 知识库中已有一个名为"产品手册.pdf"的文档
    - When: 用户再次上传名为"产品手册.pdf"的文档
    - Then: 系统接受上传，两份文档以不同文档 ID 共存

- [x] **AC-029**: PDF 文件不包含表格时回退纯文本解析（CR-001 新增）
    - Given: 用户上传一个不包含任何表格的纯文本 PDF 文件
    - When: 后台异步处理解析该 PDF 文件
    - Then: 解析结果为纯文本内容，不包含 Markdown 表格语法，行为与变更前一致

### 6.3 业务规则验证 (Business Rules)

- [ ] **AC-026**: 知识库描述长度限制
    - Given: 用户创建知识库时填写描述
    - When: 描述长度超过 200 个字符
    - Then: 系统拒绝创建，返回"描述长度不能超过 200 个字符"的提示

- [ ] **AC-027**: 检索结果数量限制
    - Given: 知识库中有大量文档片段
    - When: Agent 调用知识库检索工具
    - Then: 工具最多返回 5 个最相关的文档片段，按相似度降序排列

- [x] **AC-030**: PDF 表格结构完整性（CR-001 新增）
    - Given: 用户上传一个包含多行多列表格的 PDF 文件
    - When: 后台异步处理解析该 PDF 文件
    - Then: 解析结果中表格的每行单元格数量与原表格一致，单元格内容按行列顺序正确排列，表头与数据行的对应关系被保留

- [x] **AC-032**: DocumentChunk 存储分块元数据（CR-002 新增）
    - Given: 用户上传文档到知识库，文档异步处理完成
    - When: 系统保存分块信息到 DocumentChunkStore
    - Then: 每个 DocumentChunk 的 metadata 字段包含来源信息（fileName、format、pageNumber 或 headerText），前端查询分块列表时可展示来源

- [x] **AC-033**: 创建知识库时自动注册 Tool（CR-003 新增）
    - Given: 用户通过 API 创建一个新的知识库"产品文档"
    - When: 知识库创建成功后
    - Then: 系统自动为该知识库生成一个独立的 Tool（工具名：`knowledgeBase_{kbId}`），注册到 ToolRegistry，Agent 立即可使用该 Tool

- [x] **AC-034**: 删除知识库时自动注销 Tool（CR-003 新增）
    - Given: 用户删除一个已存在的知识库
    - When: 知识库删除操作完成
    - Then: 系统自动从 ToolRegistry 中移除对应 Tool，Agent 不再能调用该知识库的检索工具

- [x] **AC-035**: 系统启动时批量注册已有知识库 Tool（CR-003 新增）
    - Given: 系统重启时已存在多个知识库
    - When: Spring 容器启动完成后
    - Then: 系统自动扫描所有已有知识库，为每个知识库生成并注册 Tool，所有 Tool 在 Agent 首次对话前已就绪

## 变更日志 (Change Log)

### CR-001: PDF 表格解析优化 (2026-07-27)
**变更类型**: 扩展 (Extension)
**变更原因**: 当前 PDF 解析使用 PDFBox 的 PDFTextStripper 仅提取线性文本，无法识别表格结构，导致 PDF 中的表格信息丢失或混乱，Agent 无法回答表格相关问题。
**变更内容摘要**:
- [新增] BR-RAG-013: PDF 文档解析支持表格结构提取，表格内容转换为 Markdown 格式保留行列关系，无表格区域回退纯文本提取
- [新增] AC-028: PDF 文件包含表格时解析为 Markdown 表格格式
- [新增] AC-029: PDF 文件不包含表格时回退纯文本解析
- [新增] AC-030: PDF 表格结构完整性验证
- [修改] 功能范围 2.1: 新增"PDF 表格提取"条目
- [修改] AC 覆盖度自检: 更新覆盖范围说明

### CR-002: 分块数据携带文件元数据 (2026-07-30)
**变更类型**: 扩展 (Extension)
**变更原因**: 当前检索结果仅返回文本内容，不含来源元数据，Agent 无法引用文档来源；DocumentChunk 实体不存储分块级元数据，前端无法展示分块来源信息。
**变更内容摘要**:
- [新增] BR-RAG-018: 分块数据携带来源元数据（fileName、format、pageNumber/headerText），检索结果中包含来源信息
- [新增] AC-031: 检索结果包含来源元数据（文件名、格式、页码/章节标题等）
- [新增] AC-032: DocumentChunk 存储分块元数据
- [修改] AC 覆盖度自检: 更新覆盖范围说明

### CR-003: 知识库动态 Tool 注册 (2026-07-31)
**变更类型**: 扩展 (Extension)
**变更原因**: 原有单 Tool + 参数化调用模式下，LLM 需指定知识库名称作为参数，存在 LLM 幻觉生成未知知识库名称的风险。改为每个知识库独立注册为 Tool，由 LLM 通过 Function Calling 选择具体 Tool，消除知识库名称传递风险。
**变更内容摘要**:
- [修改] BR-RAG-011: 改为每个知识库自动注册为独立 Tool，Agent 通过选择 Tool 使用对应知识库
- [新增] BR-RAG-019: 创建/删除知识库时自动注册/注销对应 Tool
- [新增] BR-RAG-020: 系统启动时自动批量注册已有知识库 Tool
- [修改] AC-006: 改为 Agent 选择知识库 Tool 并检索
- [修改] AC-007: 改为基于知识库 Tool 检索结果回答
- [新增] AC-033: 创建知识库时自动注册 Tool
- [新增] AC-034: 删除知识库时自动注销 Tool
- [新增] AC-035: 系统启动时批量注册已有知识库 Tool
