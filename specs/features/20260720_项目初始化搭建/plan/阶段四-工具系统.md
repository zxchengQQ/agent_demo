## 一、任务概述

实现 `agent-demo-tools` 模块，提供 Agent 可调用的工具集与注册中心。工具是 Agent 的"手脚"，通过 LangChain4j 的 `@Tool` 注解声明，框架自动生成 JSON Schema 传递给 LLM，由 LLM 决定何时调用。

## 二、依赖关系

### 2.1 前置依赖
- **阶段一**：tools 模块的 pom.xml 与包结构
- **阶段二**：使用 `ErrorCode`、`BusinessException`、`JsonUtils`

### 2.2 被依赖（下游影响）
- **阶段六（agent）**：Agent 构建 AiServices 时通过 ToolRegistry 获取工具列表
- **阶段七（mcp）**：MCP 服务端可将本模块工具暴露给外部 Agent
- 若 ToolRegistry 接口变更，需同步评估 agent 层、mcp 层调用方

## 四、子任务详情

### 4.1 任务 4.1：工具注册中心 ToolRegistry

- **目标**：集中管理所有工具，支持按需获取与动态注册
- **接口设计**：
  ```java
  @Component
  public class ToolRegistry {
      // 获取所有已注册工具（用于构建 AiServices）
      public List<Object> listTools();
      // 按名称获取工具
      public Object getTool(String name);
      // 动态注册工具（运行时新增）
      public void register(Object tool);
      // 获取工具规格说明（供 LLM 参考）
      public List<ToolSpec> listToolSpecs();
  }
  ```
- **实现要点**：
  - Spring 启动时自动扫描所有带 `@Component` + `@Tool` 注解的 Bean
  - 通过 `ApplicationContext` 获取所有工具 Bean
  - 提供 `register` 方法支持运行时动态添加（如 MCP 加载的外部工具）
  - 线程安全：使用 `CopyOnWriteArrayList` 存储工具列表
- **调用方**：agent 层（构建 AiServices 时调用 listTools）
- **接口变更影响**：listTools 返回类型变更需同步 agent 层

### 4.2 任务 4.2：内置工具-计算器 CalculatorTool

- **目标**：提供数学表达式计算能力
- **实现要点**：
  - `@Component` + `@Tool` 注解
  - 方法：`@Tool("计算数学表达式，支持加减乘除、幂运算") double calculate(String expression)`
  - 使用 JDK 内置 `ScriptEngineManager`（JavaScript 引擎）计算表达式
  - 异常处理：表达式非法时抛出 `BusinessException(ErrorCode.TOOL_EXECUTION_FAILED)`
- **示例**：Agent 调用 `calculate("2^32")` 返回 `4294967296.0`
- **核心逻辑注释**：注明表达式计算的安全边界（禁止文件/网络访问的 JS 代码）

### 4.3 任务 4.3：内置工具-时间查询 TimeTool

- **目标**：提供当前时间、日期、时区查询
- **实现要点**：
  - 方法1：`@Tool("获取当前时间") String getCurrentTime()`
  - 方法2：`@Tool("获取指定时区的当前时间") String getCurrentTimeByZone(String zoneId)`
  - 基于 `java.time` API
  - 默认时区：Asia/Shanghai（通过配置可改）
- **调用方**：Agent 自主决定何时调用

### 4.4 任务 4.4：内置工具-HTTP 请求 HttpTool

- **目标**：提供 HTTP GET/POST 请求能力，支持联网搜索场景
- **实现要点**：
  - 方法1：`@Tool("发起 HTTP GET 请求") String httpGet(String url)`
  - 方法2：`@Tool("发起 HTTP POST 请求") String httpPost(String url, String body)`
  - 基于 Spring 的 `RestTemplate` 或 `WebClient`
  - 超时配置：连接 5s，读取 30s
  - 响应长度限制：截断超过 10KB 的响应
- **安全措施**：
  - URL 白名单/黑名单（预留扩展点）
  - 禁止访问内网地址（防止 SSRF）
  - 响应内容记录日志（便于审计）
- **核心逻辑注释**：注明 SSRF 防护逻辑

### 4.5 任务 4.5：内置工具-文件读取 FileReadTool

- **目标**：提供只读文件能力，Agent 可读取本地文件内容
- **实现要点**：
  - 方法：`@Tool("读取指定路径文件内容") String readFile(String path)`
  - **只读**：不提供写操作，防止 Agent 破坏文件
  - 路径限制：只能读取配置的允许目录（如 `./data/`）
  - 文件大小限制：超过 1MB 拒绝读取
  - 编码：统一 UTF-8
- **安全措施**：
  - 路径遍历攻击防护（禁止 `../`）
  - 配置允许的根目录白名单
- **核心逻辑注释**：注明路径安全校验逻辑

### 4.6 任务 4.6：验证

- **目标**：验证工具注册与调用正确性
- **测试内容**：
  - `ToolRegistryTest`：验证启动后注册的工具数量 ≥ 4
  - `CalculatorToolTest`：验证 `2+3` 返回 5，`2^10` 返回 1024
  - `TimeToolTest`：验证当前时间格式正确
  - `HttpToolTest`：验证可访问公开 API（如 `https://httpbin.org/get`）
  - `FileReadToolTest`：验证可读取测试文件、拒绝越界路径
- **验证命令**：`mvn test -pl agent-demo-tools`

## 五、关键接口设计

### 5.1 ToolRegistry 接口签名（影响 agent 层、mcp 层）
```java
public List<Object> listTools();
public void register(Object tool);
```
**调用方枚举**：
- agent 层 `SimpleAgent`：构建 AiServices 时调用 listTools()
- mcp 层 `McpServer`：将工具暴露为 MCP 工具时调用 listTools()

### 5.2 工具定义规范
```java
@Component
public class XxxTool {
    @Tool("工具描述，供 LLM 决策时参考")
    public String doSomething(String param) {
        // 实现
    }
}
```
**规范**：
- 所有工具类必须加 `@Component`（被 Spring 扫描）
- 工具方法必须加 `@Tool` 注解，描述清晰
- 参数类型使用基础类型（String/int/double 等），便于 LLM 生成参数

## 七、风险与注意事项

1. **工具描述质量**：`@Tool` 注解的描述直接影响 LLM 决策准确性，描述需清晰说明功能与参数含义
2. **SSRF 防护**：HttpTool 必须禁止访问内网地址（10.x、172.16-31.x、192.168.x、127.x），防止 Agent 被诱导攻击内网
3. **路径安全**：FileReadTool 必须校验路径遍历攻击，规范化路径后检查是否在允许目录内
4. **工具执行超时**：所有工具应有超时机制，防止单个工具卡死整个 Agent 循环
5. **工具数量控制**：单个 Agent 绑定的工具不宜过多（建议 ≤ 10），过多会降低 LLM 决策准确率
6. **幂等性**：工具应尽量设计为幂等，支持重试（LLM 可能重复调用同一工具）
7. **返回内容长度**：工具返回内容过长会消耗大量 Token，需截断或摘要
