# 功能需求说明书 (Feature Requirements Document)

## 1. 背景与价值 (Context & Value)

*   **背景**: agent-demo 项目后端 RAG 知识库模块已完整实现（知识库管理、文档上传与异步处理、向量语义检索、Agent 工具集成），但前端仅有对话页面，缺乏知识库管理界面。用户当前只能通过 Swagger 或命令行调用接口管理知识库，操作门槛高，无法直观查看文档处理进度，也无法在对话中便捷地指定知识库。本期为 RAG 功能补齐对应的前端页面。
*   **目标**: 为 RAG 知识库能力提供可视化管理界面，用户可通过页面完成知识库与文档的全生命周期管理，并能在对话中便捷地选择关联知识库，形成"管理知识库 -> 上传文档 -> 对话检索"的完整闭环体验。
*   **关联**: `specs/features/2026-07-24/RAG知识库问答/RAG知识库问答.md`（后端 RAG 模块需求，第 2.2 节明确"前端知识库管理界面 - 后续迭代"）；KNOWLEDGE_BASE.md 第九章 RAG 业务规则（BR-RAG-001~012）；前端设计系统 Refined Dark Tech

## 2. 功能范围 (Scope)

### 2.1 本次范围（In Scope）

*   **顶部导航**：在"对话"与"知识库"两个主页面间切换
*   **知识库管理页面**：左右分栏布局（左侧知识库列表，右侧文档列表）
*   **知识库管理**：创建知识库、查看知识库列表、删除知识库（二次确认，级联删除提示）
*   **文档管理**：拖拽/点击批量上传文档、查看文档列表、文档处理状态自动轮询展示、删除文档
*   **对话知识库集成**：对话输入框旁增加知识库选择器，支持"自动"模式与手动选择（可多选），按会话维度保持状态
*   **设计风格**：遵循现有 Refined Dark Tech（精致暗色科技风）设计系统
*   **文档格式**：纯文本（.txt）、Markdown（.md）、PDF（.pdf）

### 2.2 不在本次范围（Out of Scope）

*   知识库重命名/编辑描述 - 后续迭代，本期仅支持创建和删除
*   文档内容预览/在线阅读 - 后续迭代，需考虑大文件性能与安全
*   文档重新处理（失败后重试） - 后续迭代，需后端支持重处理接口
*   知识库检索测试工具（独立于对话的检索调试入口） - 后续迭代
*   知识库导入/导出 - 后续迭代
*   多用户权限控制 - 暂不考虑，本项目为学习示例无认证机制
*   Word（.docx）/ Excel（.xlsx）等 Office 格式 - 受后端能力限制，后续随后端扩展
*   知识库选择器的"@提及语法"交互 - 后续迭代，学习成本较高

## 3. 用户角色 (Actors)

*   **学习者/开发者**: 通过知识库管理页面创建知识库、上传文档、查看处理进度，并在对话中验证检索效果
*   **对话用户**: 在对话过程中通过知识库选择器指定检索范围，获得基于知识库的回答

## 4. 用户故事 (User Stories)

*   **US-001**: 作为 **学习者**，我想要 **在可视化页面中创建和管理知识库**，以便 **按主题分类组织不同领域的文档，替代命令行操作**。
    *   关联验收标准：AC-001, AC-002, AC-003, AC-004, AC-005, AC-006, AC-016, AC-017

*   **US-002**: 作为 **学习者**，我想要 **拖拽上传文档并实时查看处理进度**，以便 **了解文档从上传到可检索的全过程，及时发现处理失败**。
    *   关联验收标准：AC-007, AC-008, AC-009, AC-010, AC-022, AC-023, AC-024, AC-025, AC-035

*   **US-003**: 作为 **对话用户**，我想要 **在对话时选择关联的知识库**，以便 **精准检索指定知识库内容，或在无需检索时让 Agent 自主决策**。
    *   关联验收标准：AC-011, AC-012, AC-013, AC-014, AC-015, AC-028, AC-029

*   **US-004**: 作为 **学习者**，我想要 **查看文档切分后的分块详情**，以便 **了解文档是如何被分块和向量化的，便于调试检索效果和优化分块参数**。
    *   关联验收标准：AC-038, AC-039, AC-040, AC-041, AC-042

*   **US-005**: 作为 **对话用户**，我想要 **在收到助手回答后看到使用的知识库来源信息**，以便 **了解回答基于哪些文档片段生成，验证回答的准确性和可信度**。
    *   关联验收标准：AC-043, AC-044, AC-045

## 5. 详细需求与流程 (Detailed Requirements)

### 5.1 核心流程

**流程 A - 顶部导航切换：**

1. 用户进入应用后，默认展示"对话"页面（保持现有行为）
2. 顶部导航栏提供"对话"和"知识库"两个入口
3. 点击"知识库"切换到知识库管理页面；点击"对话"切换回对话页面
4. 页面切换不影响各自状态（如对话页的会话选择、知识库页的选中知识库）

**流程 B - 知识库管理：**

1. 用户进入知识库页面，左侧展示知识库列表（名称、文档数、创建时间）
2. 用户点击"新建知识库"按钮，弹出创建表单，填写名称（必填）和描述（可选）
3. 提交后知识库出现在列表中，自动选中该知识库
4. 用户点击列表中某知识库，右侧展示该知识库下的文档列表
5. 用户点击知识库的"删除"按钮，弹出二次确认框（提示将连带删除 N 个文档），确认后删除

**流程 C - 文档管理：**

1. 用户选中某知识库后，右侧展示文档列表（文件名、大小、格式、状态、上传时间）
2. 用户通过拖拽文件到上传区域，或点击上传区域选择文件，支持多文件批量上传
3. 上传后文档立即出现在列表中，状态为"待处理"
4. 系统自动轮询"处理中"状态文档的状态（每 3 秒），状态变为"已完成"或"失败"后停止轮询
5. 用户可点击文档的"删除"按钮直接删除文档（Toast 提示）

**流程 D - 对话知识库集成：**

1. 用户在对话页输入框旁看到知识库选择器，默认显示"自动"
2. 用户可点击选择器，展开知识库列表（多选），可选择一个或多个知识库
3. 选择后发送消息，Agent 在指定知识库中检索；选择"自动"时 Agent 自主决策
4. 切换会话时，知识库选择状态跟随会话保持（不同会话互不影响）

**流程 E - 文档分块详情查看：**

1. 用户在文档列表中，对状态为"已完成"的文档，点击"查看分块"按钮
2. 右侧滑出抽屉面板，展示该文档的所有分块列表
3. 每个分块显示：分块索引（如"分块 1/10"）、文本内容（截断显示，点击可展开完整内容）、字符数
4. 用户可滚动查看所有分块，点击关闭按钮或抽屉外部区域关闭面板

**流程 F - 对话知识库来源展示（CR-002 新增）：**

1. 用户发送消息后，Agent 在 ReAct 循环中调用 KnowledgeRetrieverTool 检索知识库
2. 检索结果文本通过 SSE observation 事件推送到前端，内含 `【片段N】来源: {知识库名}/{文件名}` 格式的来源信息
3. 前端解析 observation 事件，提取所有来源片段（知识库名 + 文件名）
4. 流式完成后，助手消息底部显示折叠的"引用来源"条，列出本次回答使用的所有知识库和文档文件
5. 用户可展开引用条查看具体来源列表，每条来源显示 `{知识库名} / {文件名}`
6. 若 Agent 未使用知识库检索（未触发工具调用或检索无结果），引用条不显示

### 5.2 交互/界面规则 (UI/UX Rules)

*   **导航栏**：顶部固定导航栏，当前激活项高亮显示，切换时无页面刷新（单页应用）
*   **知识库列表**：按创建时间倒序排列，选中项高亮，每项展示名称、文档数、创建时间
*   **创建表单**：弹窗形式，名称输入框实时校验格式和长度，描述输入框可选，字数计数
*   **删除确认**：知识库删除需弹窗二次确认，明确提示"将连带删除 N 个文档及向量数据，不可恢复"；文档删除直接执行并 Toast 提示
*   **上传区域**：拖拽时高亮提示，支持点击选择；批量上传时逐个处理，每个文件独立显示上传和处理状态
*   **状态展示**：待处理（灰色标签）、处理中（加载动画 + 蓝色标签）、已完成（绿色标签 + 分块数）、失败（红色标签 + 失败原因，hover 显示完整原因）
*   **知识库选择器**：下拉多选，默认"自动"；选中知识库后显示为标签集合；流式输出过程中禁用选择器
*   **空状态**：无知识库时引导创建；知识库无文档时引导上传
*   **错误提示**：接口异常时 Toast 提示，不打断页面操作
*   **设计风格**：遵循 Refined Dark Tech（深蓝黑底 #0a0e1a + 青色 accent #00d4b8），与现有对话页一致

### 5.3 业务规则 (Business Rules)

> 以下规则来源于后端已定义的 BR-RAG-001~012，前端需在界面层体现并校验。

*   **BR-RAG-FE-001**: 知识库名称长度 1-50 个字符，仅允许中英文、数字、下划线和连字符（前端实时校验，提交前拦截）
*   **BR-RAG-FE-002**: 知识库名称全局唯一（前端提交后接收后端唯一性校验结果并提示）
*   **BR-RAG-FE-003**: 知识库描述长度不超过 200 个字符（前端实时字数计数与拦截）
*   **BR-RAG-FE-004**: 单个文档大小不超过 10MB（前端上传前校验，超限直接拦截不发起请求）
*   **BR-RAG-FE-005**: 支持的文档格式：txt、md、pdf（前端按扩展名校验，不支持格式直接拦截）
*   **BR-RAG-FE-006**: 文档处理状态流转：待处理 -> 处理中 -> 已完成/失败（前端轮询展示，状态终态后停止轮询）
*   **BR-RAG-FE-007**: 删除知识库时级联删除其下所有文档和向量数据（前端确认框需明示连带删除数量）
*   **BR-RAG-FE-008**: 知识库选择器状态按会话维度保持，切换会话互不影响，同一会话内保持状态（与深度思考开关行为一致，参考 BR-FE-011）
*   **BR-RAG-FE-009**: 知识库选择按消息维度控制（发送消息时使用当前选择器的知识库配置，不影响历史消息）
*   **BR-RAG-FE-010**: 文档分块详情仅在文档状态为"已完成"时可查看（处理中/待处理/失败的文档不展示查看入口），分块数据由后端在文档处理完成时持久化存储
*   **BR-RAG-FE-011**: 对话中使用知识库时，助手消息底部显示折叠的"引用来源"条，列出使用的知识库和文档文件，点击可展开查看详情；未使用知识库时不显示

## 6. 验收标准 (Acceptance Criteria)

> **重要**：以下验收标准是后续技术方案、任务规划和 TDD 测试用例的直接依据。每条 AC 必须使用 Given-When-Then 格式，必须可被测试验证。

### 6.1 正常流程 (Happy Path)

- [ ] **AC-001**: 顶部导航切换页面
    - Given: 用户已进入应用，当前在对话页面
    - When: 用户点击顶部导航栏的"知识库"入口
    - Then: 页面切换到知识库管理页面，"知识库"导航项高亮；再点击"对话"切回对话页，对话页的会话选择状态保持不变

- [ ] **AC-002**: 知识库页面左右分栏布局
    - Given: 用户进入知识库管理页面
    - When: 页面加载完成
    - Then: 左侧展示知识库列表区域，右侧展示文档列表区域；左侧选中某知识库时，右侧展示该知识库的文档

- [ ] **AC-003**: 查看知识库列表
    - Given: 系统中已存在至少一个知识库
    - When: 用户进入知识库管理页面
    - Then: 左侧列表展示所有知识库，每项显示名称、文档数量、创建时间，按创建时间倒序排列

- [ ] **AC-004**: 创建知识库
    - Given: 用户在知识库管理页面
    - When: 用户点击"新建知识库"按钮，在弹窗中填写合法名称和描述，点击"确定"
    - Then: 弹窗关闭，新知识库出现在列表中并自动选中，右侧切换为该知识库的文档列表（空状态）

- [ ] **AC-005**: 选中知识库查看文档列表
    - Given: 左侧知识库列表中存在多个知识库
    - When: 用户点击列表中某个知识库
    - Then: 该知识库高亮选中，右侧展示该知识库下所有文档列表（文件名、大小、格式、状态、上传时间）

- [ ] **AC-006**: 删除知识库（二次确认）
    - Given: 用户选中一个包含 3 个文档的知识库
    - When: 用户点击该知识库的"删除"按钮，弹出确认框显示"将连带删除 3 个文档及向量数据，不可恢复"，用户点击"确认删除"
    - Then: 知识库及其下所有文档从列表中移除，Toast 提示"删除成功"；若删除的是当前选中知识库，右侧切换为空状态

- [ ] **AC-007**: 拖拽上传文档
    - Given: 用户已选中一个知识库，右侧文档列表区域有上传区
    - When: 用户将一个 .txt 文件拖拽到上传区域
    - Then: 上传区域高亮反馈，文件开始上传，上传成功后文档出现在列表中，状态为"待处理"

- [ ] **AC-008**: 批量上传文档
    - Given: 用户已选中一个知识库
    - When: 用户同时选择 3 个文件（.txt、.md、.pdf）上传
    - Then: 3 个文件逐个上传并出现在文档列表中，各自独立显示状态，互不影响

- [ ] **AC-009**: 文档处理状态自动轮询
    - Given: 文档列表中存在状态为"处理中"的文档
    - When: 文档处理在后端进行中
    - Then: 前端每 3 秒自动轮询该文档状态，"处理中"状态显示加载动画；状态变为"已完成"或"失败"后停止对该文档的轮询

- [ ] **AC-010**: 删除文档
    - Given: 文档列表中存在一个文档
    - When: 用户点击该文档的"删除"按钮
    - Then: 文档直接从列表中移除（无二次确认），Toast 提示"删除成功"

- [ ] **AC-011**: 知识库选择器展示
    - Given: 用户在对话页面
    - When: 页面加载完成
    - Then: 输入框旁展示知识库选择器，默认值为"自动"，与深度思考开关并列

- [ ] **AC-012**: 选择"自动"模式发送消息
    - Given: 知识库选择器为"自动"模式（默认）
    - When: 用户发送消息
    - Then: 消息正常发送，Agent 自主判断是否检索知识库及检索哪个知识库（与现有行为一致）

- [ ] **AC-013**: 手动选择知识库发送消息
    - Given: 系统中存在知识库"产品手册"
    - When: 用户在选择器中选择"产品手册"，然后发送消息
    - Then: 消息发送时携带选中的知识库信息，Agent 在"产品手册"知识库中检索

- [ ] **AC-014**: 多选知识库发送消息
    - Given: 系统中存在知识库"产品手册"和"常见问题"
    - When: 用户在选择器中同时选择两个知识库，然后发送消息
    - Then: 消息发送时携带两个选中的知识库信息，Agent 在指定范围内检索

- [ ] **AC-015**: 知识库选择器会话级保持
    - Given: 用户在会话 A 中选择了"产品手册"知识库
    - When: 用户切换到会话 B，再切回会话 A
    - Then: 会话 A 的知识库选择保持为"产品手册"；会话 B 的知识库选择为默认"自动"（互不影响）

- [ ] **AC-038**: 查看文档分块列表
    - Given: 文档列表中存在一个状态为"已完成"的文档（分块数为 10）
    - When: 用户点击该文档的"查看分块"按钮
    - Then: 右侧滑出抽屉面板，展示该文档的 10 个分块列表，每个分块显示索引编号（如"分块 1/10"）、文本内容（截断显示）、字符数

- [ ] **AC-039**: 分块内容展开查看
    - Given: 抽屉面板已打开，某分块的文本内容被截断显示
    - When: 用户点击该分块的"展开"按钮
    - Then: 展开显示完整分块文本内容；再次点击"收起"恢复截断显示

- [ ] **AC-043**: 助手消息底部显示折叠引用条
    - Given: Agent 在对话中调用了知识库检索工具并返回了检索结果
    - When: 流式回答完成
    - Then: 助手消息底部显示折叠的"引用来源"条，标题显示引用数量（如"引用来源 (3)"），列出本次回答使用的知识库名和文档文件名

- [ ] **AC-044**: 展开引用来源详情
    - Given: 引用来源条已显示在助手消息底部
    - When: 用户点击引用条展开
    - Then: 展开显示具体来源列表，每条来源显示 `{知识库名} / {文件名}`；再次点击可收起

### 6.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-016**: 空状态-无知识库
    - Given: 系统中尚未创建任何知识库
    - When: 用户进入知识库管理页面
    - Then: 左侧列表区域展示空状态引导文案（如"还没有知识库，点击新建创建第一个"），并提供"新建知识库"入口

- [ ] **AC-017**: 空状态-知识库无文档
    - Given: 用户选中一个没有文档的知识库
    - When: 右侧文档列表区域加载完成
    - Then: 展示空状态引导文案（如"还没有文档，拖拽文件到此处上传"），并展示上传区域

- [ ] **AC-018**: 知识库名称超长输入校验
    - Given: 用户在创建知识库弹窗的名称输入框中输入
    - When: 输入超过 50 个字符
    - Then: 输入框实时提示"名称不能超过 50 个字符"，"确定"按钮禁用

- [ ] **AC-019**: 知识库名称非法字符校验
    - Given: 用户在创建知识库弹窗的名称输入框中输入
    - When: 输入包含非法字符（如空格、@、#、特殊符号等，仅允许中英文/数字/下划线/连字符）
    - Then: 输入框实时提示"仅允许中英文、数字、下划线和连字符"，"确定"按钮禁用

- [ ] **AC-020**: 知识库名称重复创建
    - Given: 系统中已存在名为"产品手册"的知识库
    - When: 用户创建新知识库时填写名称"产品手册"并提交
    - Then: 提交后弹窗内提示"知识库名称已存在"，弹窗不关闭，用户可修改名称后重试

- [ ] **AC-021**: 知识库描述超长输入校验
    - Given: 用户在创建知识库弹窗的描述输入框中输入
    - When: 输入超过 200 个字符
    - Then: 输入框实时提示"描述不能超过 200 个字符"并显示字数计数（如 205/200），"确定"按钮禁用

- [ ] **AC-022**: 文档超大上传校验
    - Given: 用户拖拽或选择了一个 15MB 的文件
    - When: 文件准备上传
    - Then: 前端拦截上传，Toast 提示"文件大小不能超过 10MB"，不发起上传请求

- [ ] **AC-023**: 文档格式不支持校验
    - Given: 用户拖拽或选择了一个 .docx 文件
    - When: 文件准备上传
    - Then: 前端拦截上传，Toast 提示"仅支持 txt、md、pdf 格式"，不发起上传请求

- [ ] **AC-024**: 文档处理失败状态展示
    - Given: 某文档在后端处理过程中失败
    - When: 前端轮询到该文档状态为"失败"
    - Then: 文档列表中该文档状态标签显示为红色"失败"，并展示失败原因；hover 失败原因显示完整内容；停止对该文档的轮询

- [ ] **AC-025**: 批量上传部分失败
    - Given: 用户批量上传 3 个文件（1 个超大、1 个格式不支持、1 个合法）
    - When: 前端校验后
    - Then: 合法文件正常上传并出现在列表中；超大文件 Toast 提示"文件大小不能超过 10MB"；不支持格式文件 Toast 提示"仅支持 txt、md、pdf 格式"；3 个文件的校验结果互不影响

- [ ] **AC-026**: 删除知识库取消确认
    - Given: 用户点击了某知识库的"删除"按钮，弹出确认框
    - When: 用户点击"取消"
    - Then: 确认框关闭，知识库不被删除，列表保持不变

- [ ] **AC-027**: 接口异常错误提示
    - Given: 用户执行某操作（如创建知识库、上传文档、删除等）
    - When: 后端接口返回错误或网络异常
    - Then: Toast 提示错误信息（展示后端返回的错误消息或"网络异常，请稍后重试"），不阻塞页面其他操作

- [ ] **AC-028**: 知识库选择器-无可用知识库
    - Given: 系统中尚未创建任何知识库
    - When: 用户在对话页点击知识库选择器
    - Then: 选择器下拉列表为空，提示"暂无知识库，请先在知识库页面创建"，默认保持"自动"模式

- [ ] **AC-029**: 流式输出时选择器禁用
    - Given: 用户发送消息后，Agent 正在流式回复中
    - When: 流式输出过程中
    - Then: 知识库选择器置灰禁用，不可操作；流式输出完成后恢复可操作（与输入框禁用行为一致，参考 BR-FE-009）

- [ ] **AC-040**: 非已完成文档不可查看分块
    - Given: 文档列表中存在状态为"待处理"、"处理中"或"失败"的文档
    - When: 页面渲染文档列表
    - Then: 这些文档不显示"查看分块"按钮（或按钮禁用），仅"已完成"状态的文档可点击查看分块

- [ ] **AC-041**: 无分块数据的空状态
    - Given: 文档状态为"已完成"但分块数为 0
    - When: 用户点击"查看分块"
    - Then: 抽屉面板打开，展示空状态提示"该文档无分块数据"

- [ ] **AC-042**: 分块查询接口异常
    - Given: 用户点击"查看分块"按钮
    - When: 后端接口返回错误或网络异常
    - Then: Toast 提示错误信息（展示后端错误消息或"网络异常，请稍后重试"），不打开抽屉面板

- [ ] **AC-045**: 未使用知识库时不显示引用条
    - Given: Agent 在对话中未调用知识库检索工具，或调用了但检索无结果
    - When: 流式回答完成
    - Then: 助手消息底部不显示"引用来源"条

### 6.3 业务规则验证 (Business Rules)

- [ ] **AC-030**: 知识库名称格式规则
    - Given: 用户在创建知识库弹窗中输入名称
    - When: 名称长度在 1-50 个字符之间，且仅包含中英文、数字、下划线、连字符
    - Then: 校验通过，"确定"按钮可点击；反之实时提示对应错误并禁用按钮

- [ ] **AC-031**: 知识库名称唯一性规则
    - Given: 用户提交创建知识库请求
    - When: 后端返回名称重复错误（错误码 5307）
    - Then: 弹窗内提示"知识库名称已存在"，弹窗保持打开，用户可修改名称后重新提交

- [ ] **AC-032**: 知识库描述长度规则
    - Given: 用户在创建知识库弹窗中输入描述
    - When: 描述为空或长度不超过 200 个字符
    - Then: 校验通过；描述超过 200 字符时实时拦截并提示

- [ ] **AC-033**: 文档大小限制规则
    - Given: 用户上传文档
    - When: 单个文件大小超过 10MB
    - Then: 前端拦截上传，Toast 提示"文件大小不能超过 10MB"，不发起请求

- [ ] **AC-034**: 文档格式白名单规则
    - Given: 用户上传文档
    - When: 文件扩展名不在 txt/md/pdf 范围内
    - Then: 前端拦截上传，Toast 提示"仅支持 txt、md、pdf 格式"，不发起请求

- [ ] **AC-035**: 文档状态流转展示规则
    - Given: 文档上传成功后出现在列表中
    - When: 文档经历状态流转
    - Then: 依次展示"待处理"（灰色）-> "处理中"（蓝色 + 加载动画）-> "已完成"（绿色 + 分块数）/ "失败"（红色 + 失败原因）；终态后停止轮询

- [ ] **AC-036**: 删除知识库级联提示规则
    - Given: 用户点击知识库的"删除"按钮
    - When: 弹出确认框
    - Then: 确认框明确提示"将连带删除 N 个文档及向量数据，不可恢复"（N 为该知识库下文档数量）

- [ ] **AC-037**: 知识库选择器状态保持规则
    - Given: 用户在会话 A 中选择了知识库，切换到会话 B 后又切回 A
    - When: 切换会话操作
    - Then: 会话 A 恢复其之前的知识库选择；会话 B 使用其自己的选择或默认"自动"；两个会话的选择互不影响
