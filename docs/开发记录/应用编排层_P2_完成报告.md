## 6. 遇到的问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|------|
| Maven 沙箱拦截本地仓库写入 | TRAE 沙箱拦截 D:\maven\repo metadata 写入 | 使用 `-o` 离线模式（P1 已验证） |
| Task-02 GREEN 3 个测试失败 | 测试断言不精确（json.contains 误命中字段名） | 改用 readTree 顶层 key 断言，实现正确 |
| Task-04 超时被包装成 FAILED | P1 遗留缺陷：executeWithRetry 将 WorkflowTimeoutException 包装为 BusinessException | 超时/取消异常直接上抛，协调层推送 TIMEOUT/TERMINATED（AC-023/022） |
| Task-07 并行 join 抛 CompletionException | checkCancelled 在 CompletableFuture 内抛异常被包装 | join 时解包 cause 重新抛出，协调层正确捕获 |
| Task-07 并行 mock 返回值错乱 | mockito 多值 thenReturn 并发下非原子 | 改用 thenAnswer 按 Agent 名返回（并发安全） |
| Task-08 条件分支误命中 | params 未展开到 ctx 顶层，谓词读不到 question | 各策略 `params.forEach(ctx::write)` |
| Task-13/21 循环模板退出条件错误 | exitCondition 读 lastOutput（修订 Agent 输出）无分数 | 改为读"评分 Agent"输出（语义准确） |
| Task-19 前端 build TS 错误 | 未使用的 import WorkflowParameter | 移除 |
| Task-20 历史列表渲染 undefined | WorkflowPage 测试 mock listExecutions 未设返回值 | 测试中显式 mockResolvedValue([]) |
