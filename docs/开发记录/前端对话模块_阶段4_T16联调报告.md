## 2. 后端 SSE 流式接口验证

### 2.1 首次对话（AC-002、AC-010、AC-020）

**请求**：`POST /api/agent/chat/stream`，body: `{"sessionId":"","message":"你好，请用一句话介绍自己"}`

**结果**：
- ✅ HTTP 200，Content-Type: `text/event-stream`
- ✅ `event:session` → 返回新 sessionId `6aec473f740f4ac8b6d907345523eb42`（透明续聊：首次对话自动新建会话）
- ✅ 多个 `event:token` → 逐字流式输出大模型回复（AC-002 流式输出、AC-020 逐字显示）
- ✅ `event:done` → 携带耗时 3995ms，流式完成（AC-003 保存会话纪录）

### 2.2 多轮上下文（AC-004）

**请求**：使用上一轮 sessionId `6aec473f740f4ac8b6d907345523eb42`，message: `"我刚才说了什么？请用一句话回答"`

**结果**：
- ✅ HTTP 200
- ✅ **无 session 事件**（sessionId 有效，未触发新建，验证透明续聊逻辑正确）
- ✅ 48 个 `event:token` 事件（LLM 基于上下文正常回复，证明 ChatMemory 多轮上下文生效）
- ✅ `event:done` 事件正常

### 2.3 空消息校验（AC-014）

**请求**：body: `{"sessionId":"","message":""}`

**结果**：
- ✅ HTTP 400
- ✅ 错误信息：`{"success":false,"code":400,"message":"消息内容不能为空"}`

### 2.4 超长消息校验（AC-015）

**请求**：body: `{"sessionId":"","message":"aaa...（4001 字符）"}`

**结果**：
- ✅ HTTP 400（@Size(max=4000) 校验生效）

### 2.5 后端日志

- 2 次 INFO：`Agent 流式对话: sessionId=...`（两次正常对话）
- 2 次 WARN：`参数校验异常`（空消息、超长消息，预期行为）
- **无 ERROR 日志**
