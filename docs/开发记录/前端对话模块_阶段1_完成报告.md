## 6. 遇到的问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| @WebMvcTest 找不到 @SpringBootConfiguration | web 模块无 @SpringBootApplication（在 bootstrap 模块） | 创建 `WebTestApplication` 测试启动类 |
| PowerShell 拆分 `-Dproperty=value` 参数 | PowerShell 5 对 `=` 的解析 | 用引号包裹：`"-Dtest=XXX"` |
| lambda 引用非 final 变量 | sessionId 在 if 中被重新赋值 | 引入 `effectiveSessionId` final 变量 |
| -q 模式下 exit code 与实际测试结果不一致 | PowerShell 管道影响 exit code | 改用 surefire 报告文件确认结果 |
