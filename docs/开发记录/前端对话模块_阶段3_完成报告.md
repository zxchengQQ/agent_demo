## 2. 设计方向（frontend-design 技能指导）

### 美学方向：Refined Dark Tech（精致暗色科技风）

| 维度 | 决策 |
|------|------|
| **字体** | JetBrains Mono（显示/代码）+ Noto Sans SC（中文正文） |
| **配色** | 深蓝黑底（#0a0a14）+ 青色 accent（#00d9ff） |
| **记忆点** | 流式光标闪烁动画 + 消息左侧 accent 条 |
| **布局** | 左右分栏（280px 侧边栏 + 自适应对话框） |

### DFII 评分：15（优秀）
- Aesthetic Impact: 4
- Context Fit: 4
- Implementation Feasibility: 4
- Performance Safety: 5
- Consistency Risk: 2

### 设计系统（CSS 变量）
- 配色：12 个颜色变量（背景/accent/文字/状态）
- 字体：2 个字体栈（display + body）
- 间距：5 级（xs/sm/md/lg/xl）
- 圆角：3 级（sm/md/lg）
- 阴影：2 种（sm + glow）
- 动画：blink（光标）+ fadeIn（消息淡入）

## 3. 组件实现

### T-10：App.vue 左右分栏布局
- 左侧 280px SessionList + 右侧自适应 ChatWindow
- onMounted 调用 store.init()（AC-001）
- 占满视口高度，无滚动条溢出

### T-11：MessageItem.vue
- 用户消息右对齐（蓝色背景 + 右侧 accent 条）
- 助手消息左对齐（深色背景 + 左侧 accent 条 + AI 头像）
- 流式光标（incomplete + 有内容时显示闪烁 ▊）
- 状态标记（incomplete: "回复不完整" / error: "发生错误"）
- 消息淡入动画

### T-12：MessageList.vue
- 消息按时间正序展示
- 流式追加时自动滚动到底部（AC-020）
- 空会话显示欢迎语 + AI 图标

### T-13：MessageInput.vue
- textarea 自适应高度（最大 200px）
- 字符计数（当前/4000，AC-015）
- 发送按钮（accent 色，禁用态灰色）
- 流式时切换为"停止生成"按钮（红色 + 脉冲动画，AC-011）
- 空消息禁用发送（AC-014）
- 超长消息提示 + 禁止发送（AC-015）
- Ctrl/Cmd + Enter 快捷发送
- 流式时输入框禁用（AC-017）

### T-14：ChatWindow.vue（⚠️ 风险任务）
- 组合 MessageList + MessageInput
- 发送消息：乐观添加用户消息 -> 创建助手占位 -> 流式调用
- 透明续聊：onSession 回调更新 sessionId 关联（AC-010）
- 逐字追加：onToken 回调追加内容（AC-020）
- 流式完成：onDone 标记 complete + touchSession + 首条消息生成标题（AC-003, AC-006）
- 停止生成：AbortController.abort()（AC-011）
- 错误处理：onError 标记 error（AC-012, AC-013）

### T-15：SessionList.vue
- 会话按 updatedAt 倒序展示（AC-018）
- 顶部"新建会话"按钮
- 每个会话项：标题 + hover 显示重命名/删除按钮
- 当前选中会话高亮（左侧 accent 条）
- 重命名：输入框限 50 字符（AC-007）
- 删除：二次确认对话框（AC-008）
- 清空全部：二次确认对话框（AC-009）
- 空列表显示"暂无会话"
