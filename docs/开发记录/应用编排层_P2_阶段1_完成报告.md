## 5. 遇到的问题与解决方案

### 问题 1: Maven 沙箱拦截本地仓库写入
- **原因**: TRAE 沙箱拦截 `D:\maven\repo` 的 metadata 写入（联网检查版本）
- **解决方案**: 使用 `-o`（离线模式）运行 Maven，本地仓库已完整（P1 已验证）
- **影响**: 无，离线模式正常完成编译与测试

### 问题 2: Task-02 GREEN 阶段 3 个测试失败
- **原因**: 测试断言不精确——`json.contains("condition")` 子串匹配命中 `conditionDescription` 字段名；predicate 恒 true 却断言 false 的逻辑矛盾
- **解决方案**: 改用 `ObjectMapper.readTree` 解析顶层 key；重写矛盾断言
- **影响**: 实现代码正确（@JsonIgnore 生效），仅修正测试

### 问题 3: 全量测试暴露 mcp 模块失败
- **原因**: MCP Server 连接被拒绝（网络环境依赖，与本次改动无关）
- **解决方案**: 确认非本次改动引入，限定 app/common 模块 69 个测试全部通过
- **影响**: 无，后续集成验证时需注意 mcp 环境
