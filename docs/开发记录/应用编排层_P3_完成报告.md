## 6. 遇到的问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|------|
| PowerShell 下 mvn -Dtest 参数解析错误 | 多测试类逗号串未加引号 | 参数整体加双引号 `"-Dtest=A,B,C"` |
| Maven 报 JDK 版本不兼容 | 默认 JAVA_HOME 指向低版本 | `$env:JAVA_HOME="D:\java\jdk-17.0.7"` |
| WorkflowTemplatesTest 模板数断言失败 | 新模板未入注册表 fixture | 注册表加入 P3 模板（5 个），断言适配 |
| 路由方法测试无法直测 | 实例方法依赖构造注入 | 路由方法改 static |
| `mvn install` 本地仓库写入被拦截 | 沙箱限制 | 改用 `-pl ... -am` reactor 内构建 |
| 测试文件 TS 语法错误 | beforeEach 块多余右括号 | 修复括号 |
| 多测试套件重复 mock SSE 流逻辑 | mockSseStream 定义在单个 describe 内 | 提取为顶层共享辅助函数 |
| 集成测试 SSE 事件断言不稳定 | SSE chunk 含换行与多余 data | 用正则逐 chunk 提取事件名序列 |
| vue-tsc 报 agentName 缺失 | 恢复流事件先于面板初始化到达 | ensurePanel 参数 agentName 改可选 + 默认"步骤 N" |
| chat.test.ts 全量失败（预存在） | P2 期间 chat.ts 增加 tools 参数，测试未适配 | 补齐 mock 调用的 tools 参数 |
| SettingsPage 测试失败（预存在） | 页面新增"工具管理"标签 | 断言 2→3 个标签 |
| DocumentUploader 测试失败（预存在） | 上传前置校验需已选知识库 | mock store 的 currentKnowledgeBaseId |
| agent-demo-mcp 3 个失败 | 环境：`\\?\` 前缀路径非法字符/网络拒绝 | 判定为非 P3 环境问题，未修改（见 4.4） |
