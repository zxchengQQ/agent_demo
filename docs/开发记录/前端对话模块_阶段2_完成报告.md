## 6. 遇到的问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| npm --prefix 在 PowerShell 下异常 | PowerShell 对路径处理 | 用 cwd 参数指定工作目录 |
| vue-tsc 报 `noUnusedParameters` | tsconfig 严格模式 | 省略未使用的回调参数 |
| vue-tsc 报 `Cannot find name 'global'` | chat.test.ts 用 Node.js 的 global，tsconfig 用 DOM lib | tsconfig exclude 测试文件（测试由 vitest 运行时验证） |
| clearAll 测试失败 | clearAll 调用 createNewSession 导致 sessions 非空 | clearAll 不自动创建新会话（AC-009 列表为空，UI 层负责新建） |
