# BUG 修复报告

## 基本信息
- 日期：2026-08-13
- 报告人：AI 开发助手
- 模块/功能：工具按需加载（SimpleAgent / ToolSchemaConverter / AgentController）
- 严重级别：高
- 影响范围：所有使用工具按需加载功能的对话，未指定工具时 Agent 仍会加载并可能调用 MCP/知识库等可选工具
- 严重级别依据：直接违反"默认仅加载通用安全工具"的安全目标，未指定额外工具时 Agent 可调用用户页面新增的 MCP 服务工具（如 `mcp_web_search_search`），属于安全边界绕过，影响所有对话场景

## 问题描述
- 期望结果：用户未指定额外工具时，Agent 只能使用默认工具（`agent.tools.default-tools`），不能调用 MCP/知识库等可选工具。
- 实际结果：未指定工具时，Agent 仍调用了默认工具之外的工具，如 `mcp_web_search_search`（web_search 是用户页面添加的 MCP 服务）。

## 复现步骤（必须可复现）
1) 在前端"设置 > MCP 服务"添加 web_search MCP 服务，并确认其工具 `mcp_web_search_search` 已注册到 ToolRegistry。
2) 确保 `agent.tools.default-tools` 未包含 MCP 工具。
3) 在前端对话页不选择任何额外工具（tools 参数为空），发送一条会触发搜索/联网的问题。
4) 观察 Agent 是否调用了 `mcp_web_search_search`。

## 复现环境
- 设备/系统：Windows，Java 17 + Spring Boot 3.2.5 + LangChain4j 1.0.0
- 应用版本/配置：agent-demo 1.0.0（工具按需加载功能）
- 相关依赖或外部条件：需配置可用 LLM 模型，且存在用户添加的 MCP 服务

## 定位过程
- 关键线索：工具按需加载仅对"带 tools 参数的流式路径"生效，其他对话路径仍全量加载。
- 排查路径：
  1. `SimpleAgent.getDelegate(String modelId)`（单参版本）内部调用 `toolRegistry.listTools()` 获取**全量**工具，绑定到 AiServices。同步对话 `chat(sessionId, message, modelId)`、无 tools 的流式 `chatStream(...)` 均走此路径 → 全量工具。
  2. `SimpleAgent.chatThinkingReActStream(...)`（深度思考 ReAct 路径）内部调用 `toolSchemaConverter.convertToJson()` / `buildReActMessagesWithMemory()` 均基于 `toolRegistry.listTools()` 全量生成工具 Schema 与描述 → 深度思考模式也全量。
  3. AgentController 同步接口 `POST /api/agent/chat` 调用三参 `simpleAgent.chat(...)`（未传 tools），不走按需解析。
- 根因说明：本次迭代只让"流式 + 显式 tools"路径按需加载，其余 3 条路径（同步 chat、无 tools 流式、深度思考 ReAct）仍用全量工具，导致未指定工具时 MCP 等可选工具被默认暴露给 Agent。

## 修复方案
- 修改点说明：
  1. `ToolSchemaConverter` 新增 `convertToJson(List<Object> tools)` / `convertToDescriptionText(List<Object> tools)` 重载，仅对指定工具列表生成 Schema/描述；无参方法保留（委托 listTools 全量，向后兼容）。
  2. `SimpleAgent.getDelegate(modelId)` 单参版本改用 `toolRegistry.getDefaultTools(...)`（默认工具）替代 `listTools()` 全量，未指定工具时仅绑定默认工具。
  3. `SimpleAgent.chatThinkingReActStream(...)` 通过 `resolveSessionTools` 解析本次会话工具列表，`convertToJson(tools)` / `buildReActMessagesWithMemory(sessionId, message, tools)` 仅基于绑定工具生成。
  4. AgentController 同步 `chat()` 解析 `request.getTools()` 并调用四参 `simpleAgent.chat(sessionId, message, modelId, toolIds)`。
- 影响评估：所有对话路径统一为"默认工具 ∪ 指定工具"，未指定时仅默认工具，符合工具按需加载目标。
- 风险点：无 tools 参数的历史调用方语义从"全量工具"变为"仅默认工具"，属预期安全收紧；如需恢复全量需显式指定。
- 回滚方案：`getDelegate(modelId)` 单参版本恢复为 `toolRegistry.listTools()` 即可回到全量行为。
