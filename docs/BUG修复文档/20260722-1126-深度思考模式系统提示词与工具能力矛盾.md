# BUG 修复报告

## 基本信息
- 日期：2026-07-22
- 报告人：AI Agent（bugfix-workflow）
- 模块/功能：前端对话模块 - 深度思考模式（chatThinkingStream）
- 严重级别：中
- 影响范围：所有使用深度思考模式（enableThinking=true）的用户，当提问涉及需要工具辅助的内容（如新闻查询、网络信息获取）时触发
  - 严重级别依据：非阻断（用户可切换关闭深度思考模式绕过），但影响思考模式的回答质量和用户体验

## 问题描述
- 期望结果：深度思考模式下，模型应基于自身知识直接回答用户问题，推理过程不出现工具调用相关内容
- 实际结果：深度思考模式下，模型推理过程中尝试调用不存在的工具，正式输出中包含无意义的 XML 工具调用标签（如 `<search><query>...</query></search>`），而非有效回答

## 复现步骤（必须可复现）
1) 打开前端对话页面（http://localhost:5174/）
2) 开启"深度思考"开关
3) 在输入框输入："帮我查一下今天中国国内金融行业借贷相关的新闻"
4) 观察推理过程和正式输出

**修复前现象**：
- 推理内容出现"需要调用搜索工具"、"调用搜索工具"等表述
- 正式输出为 `<search><query>今天中国国内金融行业借贷相关新闻</query></search>`（无意义 XML 标签）

**修复后现象**：
- 推理内容说明"知识截止到2024年7月，无法获取实时新闻"，然后规划梳理近期行业动态
- 正式输出为结构化 Markdown 回答，包含借贷监管、普惠借贷支持、民间借贷治理三个层面的动态，并建议用户去权威平台查看当日最新资讯

## 定位过程
- 关键线索：思考模式（chatThinkingStream）与正常模式（chatStream）的系统提示词使用差异
- 排查路径：
  1. 阅读 `AgentController.chatStream()`，确认 enableThinking=true 时走 `simpleAgent.chatThinkingStream()` 路径
  2. 阅读 `SimpleAgent.chatThinkingStream()` 和 `buildMessagesWithMemory()`，发现使用 `agentConfig.getDefaultSystemPrompt()`
  3. 阅读 `AgentConfig`，发现默认提示词为"你是一个有用的 AI 助手，可以调用工具帮助用户解决问题。当问题需要计算、查询时间、获取网络信息时，请主动调用相应工具。"
  4. 阅读 `ArkThinkingStreamingChatModel.buildRequestBody()`，确认请求体中不包含 `tools` 字段
  5. 结论：系统提示词告诉模型"可以调用工具"，但 API 请求不传递工具定义，也不执行 ReAct 循环，导致模型矛盾
- 根因说明：思考模式路径直连方舟 API，绕过了 AiServices 的 ReAct 循环和工具绑定。但 `buildMessagesWithMemory()` 仍使用 `defaultSystemPrompt`（含工具调用引导语），导致模型在推理时尝试调用不存在的工具

## 修复方案
- 修改点说明：为思考模式添加专用系统提示词 `thinkingSystemPrompt`，不包含工具调用引导语
- 影响评估：仅影响思考模式（chatThinkingStream）路径，正常模式（chat/chatStream）不受影响
- 风险点：无显著风险。思考模式本就不支持工具调用，移除工具引导语是正确的语义对齐
- 回滚方案：将 `SimpleAgent.buildMessagesWithMemory()` 中的 `getThinkingSystemPrompt()` 改回 `getDefaultSystemPrompt()` 即可

## 变更内容
- 代码/配置改动摘要：
  1. `AgentConfig.java`：新增 `thinkingSystemPrompt` 字段，默认值"你是一个有用的 AI 助手。请基于你的知识直接回答用户的问题，无需调用任何工具。"
  2. `SimpleAgent.java`：`buildMessagesWithMemory()` 中系统提示词从 `getDefaultSystemPrompt()` 改为 `getThinkingSystemPrompt()`
