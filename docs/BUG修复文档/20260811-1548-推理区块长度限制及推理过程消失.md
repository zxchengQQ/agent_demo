# BUG 修复报告

## 基本信息
- 日期：2026-08-11
- 报告人：AI Agent
- 模块/功能：前端对话模块 - 推理折叠区块（【已思考】/【推理过程】）
- 严重级别：中
- 影响范围：
  - Bug1：深度思考/任务拆解模式，推理内容超长时撑开整个页面，需滚动整页查看
  - Bug2：深度思考模式，回答结束后【推理过程】框中的 Thought 信息消失
  - 严重级别依据：两个均为体验问题，不阻断核心对话功能，但显著影响深度思考模式的可用性和信息展示完整性

## 问题描述
- 期望结果：
  - Bug1：【已思考】和【推理过程】内容超长时应在区块内部滚动查看，不撑开整个页面
  - Bug2：回答结束后【推理过程】框中的信息应完整保留，便于用户回看
- 实际结果：
  - Bug1：【已思考】（thinking-content）和【推理过程】（react-content）无长度限制，内容超长时撑开整个页面，需要滚动整页才能看完
  - Bug2：回答结束后，【推理过程】框中的 Thought 文本消失

## 复现步骤（必须可复现）

### Bug1 复现步骤
1) 启动后端和前端服务
2) 开启"深度思考"模式，输入一个推理过程较长的复杂问题（如"逐步分析一个多步数学应用题"）
3) 展开【推理过程】区块（或流式中自动展开）
4) 观察：当推理内容超过一定长度时，整个页面被撑高，需要滚动整页才能查看全部推理内容

### Bug2 复现步骤
1) 启动后端和前端服务
2) 开启"深度思考"模式，输入一个需要多轮 ReAct 推理的问题（如"现在几点？然后计算 123*456"）
3) 流式中观察【推理过程】区块正常显示 Thought 内容
4) 等待回答结束（收到 final-answer 事件）
5) 观察：展开【推理过程】区块，发现最终答案对应的 Thought 文本消失

## 定位过程

### Bug1 定位过程
- 关键线索：页面被推理内容撑高，需要滚动整页
- 排查路径：
  1. 定位【已思考】区块样式 [MessageItem.vue](file:///d:/project_demo/agent_demo/agent-demo-frontend/src/components/MessageItem.vue) 的 `.thinking-content`（L497-505）
  2. 定位【推理过程】区块样式 `.react-content`（L541-547）
  3. 发现两者均无 `max-height` 和 `overflow-y` 限制
  4. 对比之前已修复的 `.subtask-detail`（已加 `max-height: 300px; overflow-y: auto`）
- 根因说明：`.thinking-content` 和 `.react-content` 缺少高度限制，内容超长时自然撑开父容器，导致整个消息和页面被撑高

### Bug2 定位过程
- 关键线索：回答结束后推理过程的 Thought 文本消失
- 排查路径：
  1. 定位 [ChatWindow.vue](file:///d:/project_demo/agent_demo/agent-demo-frontend/src/components/ChatWindow.vue) 中 `onFinalAnswer` 回调（L177-179）调用 `moveThoughtToContent`
  2. 定位 [session.ts](file:///d:/project_demo/agent_demo/agent-demo-frontend/src/stores/session.ts) 的 `moveThoughtToContent`（L267-280）
  3. 发现该方法把 `step.thought` 移入 `msg.content` 后执行 `step.thought = ''` 清空
  4. 确认根因：final-answer 事件触发时清空 thought，导致【推理过程】区块中该轮 Thought 文本消失
- 根因说明：`moveThoughtToContent` 的设计意图是"将最终答案 thought 移入 content 展示，同时清空避免重复展示"。但清空操作导致推理过程区块（react-block）中的 Thought 内容在回答结束后永久消失，用户无法回看完整推理过程

## 修复方案

### Bug1 修复方案
- 修改点说明：给 `.thinking-content` 和 `.react-content` 增加 `max-height: 300px; overflow-y: auto`，与之前 `.subtask-detail` 的修复一致
- 影响评估：仅影响推理区块内部样式，内容超长时在区块内滚动，不撑开页面
- 风险点：极低，纯 CSS 样式修改
- 回滚方案：移除两处 `max-height` 和 `overflow-y` 声明

### Bug2 修复方案
- 修改点说明：修改 [session.ts](file:///d:/project_demo/agent_demo/agent-demo-frontend/src/stores/session.ts) 的 `moveThoughtToContent`，移除 `step.thought = ''`，保留推理过程完整记录
- 影响评估：最终答案仍追加到 content 展示（主回复区），同时推理过程区块保留完整 Thought，不会消失。仅影响 ReAct 深度思考模式的最终回答展示，其他模式不受影响
- 风险点：最终答案的 thought 会同时出现在主回复区（content）和推理过程区（react-block），存在内容重复展示。但相比"推理过程信息消失"，保留完整记录更符合用户诉求
- 回滚方案：恢复 `step.thought = ''` 行
