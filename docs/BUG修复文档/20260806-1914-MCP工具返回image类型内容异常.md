## 问题描述

### 现象
用户通过 Agent 对话发送"帮我画一个【大象放进冰箱】的（mermaid）步骤流程图"时，mermaid-mcp 工具调用失败，返回错误：`Unsupported content type: "image"`。

### 期望结果
Agent 调用 mermaid-mcp 的 `validate_and_render_mermaid_diagram` 工具后，应正常返回图片链接或图片信息，LLM 将结果转述给用户。

### 实际结果
工具调用抛出 `BusinessException`，错误信息为 `MCP 工具调用失败 [mermaid-mcp/validate_and_render_mermaid_diagram]: Unsupported content type: "image"`。

### 复现步骤
1. 启动应用，确保 mermaid-mcp Server 已连接
2. 通过 Agent 对话发送"帮我画一个【大象放进冰箱】的（mermaid）步骤流程图"
3. Agent 调用 `mcp_mermaid_mcp_validate_and_render_mermaid_diagram` 工具
4. 工具调用失败，LLM 收到错误信息

## 根因分析

### 问题定位
- **文件**：`agent-demo-mcp/src/main/java/com/agentdemo/mcp/tool/McpToolExecutor.java`
- **行号**：第 82 行（修复前）
- **根因代码**：`return result.resultText();`

### 原因分析
LangChain4j 的 `ToolExecutionResult.resultText()` 方法仅支持 `TextContent` 类型。当 MCP Server 返回 `ImageContent` 类型时，该方法抛出 `Unsupported content type: "image"` 异常。

mermaid-mcp 的 `validate_and_render_mermaid_diagram` 工具返回的是图片内容（`ImageContent`），而非纯文本，导致 `resultText()` 方法无法处理。

### API 分析
- `ToolExecutionResult.resultText()` - 仅提取文本内容，遇到非 text 类型抛异常
- `ToolExecutionResult.resultContents()` - 返回 `List<Content>`，包含所有内容类型（text、image、audio 等）
- `Content.type()` - 返回 `ContentType` 枚举（TEXT、IMAGE、AUDIO、VIDEO、PDF）
- `ImageContent.image()` - 返回 `Image` 对象，包含 `url()`、`base64Data()`、`mimeType()`

## 修复方案

### 修复内容
在 `McpToolExecutor` 中新增 `extractResultText` 方法，替换原有的 `result.resultText()` 调用。该方法遍历 `resultContents()` 列表，根据内容类型分别处理：

1. **TEXT 类型**：提取文本内容
2. **IMAGE 类型**：提取图片 URL 或 base64 信息，转换为文本描述（LLM 可读）
3. **其他类型**：返回类型标识提示

### 改动文件

| 文件 | 改动类型 | 说明 |
|------|----------|------|
| `McpToolExecutor.java` | 修改 | 新增 `extractResultText` 方法，替换 `resultText()` 调用 |
| `McpToolExecutorTest.java` | 修改 | 新增 3 个测试用例覆盖 image 内容处理 |

### 关键代码

```java
private String extractResultText(ToolExecutionResult result) {
    List<Content> contents = result.resultContents();
    if (contents == null || contents.isEmpty()) {
        return "";
    }

    StringBuilder sb = new StringBuilder();
    for (Content content : contents) {
        if (sb.length() > 0) {
            sb.append("\n");
        }
        ContentType type = content.type();
        switch (type) {
            case TEXT -> {
                if (content instanceof TextContent tc) {
                    sb.append(tc.text());
                }
            }
            case IMAGE -> {
                if (content instanceof ImageContent ic) {
                    var image = ic.image();
                    if (image.url() != null) {
                        sb.append("[图片] 图片链接: ").append(image.url());
                    } else if (image.base64Data() != null) {
                        sb.append("[图片] 已生成 base64 格式图片数据（MIME 类型: ")
                          .append(image.mimeType()).append("）");
                    } else {
                        sb.append("[图片] 图片数据不可用");
                    }
                }
            }
            default -> sb.append("[").append(type).append("] 不支持的内容类型");
        }
    }
    return sb.toString();
}
```

## 影响范围

- **影响模块**：agent-demo-mcp（MCP 工具执行器）
- **影响范围**：所有返回非 text 类型内容的 MCP Server（不仅限于 mermaid-mcp）
- **兼容性**：完全向后兼容，原有 text 类型内容的处理逻辑不变
- **风险**：低，仅扩展内容处理能力，不修改已有逻辑

## 回滚方案

如需回滚，将 `McpToolExecutor.java` 中 `extractResultText(result)` 调用改回 `result.resultText()`，并删除 `extractResultText` 方法即可。但回滚后 mermaid-mcp 等返回 image 内容的工具将无法使用。
