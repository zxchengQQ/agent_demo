# BUG 修复报告

## 基本信息
- 日期：2026-07-28
- 报告人：AI 开发助手
- 模块/功能：知识库管理页面 - 新建知识库功能
- 严重级别：高
- 影响范围：知识库管理页面的"新建知识库"按钮完全无响应，用户无法创建知识库
- 严重级别依据：阻断核心功能，用户无法通过 UI 创建知识库，无绕过方式（除非直接调 API）

## 问题描述
- 期望结果：点击"新建知识库"按钮后，弹出创建知识库对话框（CreateKnowledgeBaseDialog）
- 实际结果：点击按钮后没有任何反应，弹窗不出现

## 复现步骤（必须可复现）
1) 启动前端开发服务器（`npm run dev`），打开浏览器访问 `http://localhost:5173`
2) 点击顶部导航栏的"知识库"切换到知识库管理页面
3) 点击左侧列表区域顶部的"+ 新建知识库"按钮
4) 观察：无弹窗出现，页面无任何变化

## 复现环境
- 设备/系统：Windows 10/11
- 应用版本：agent-demo-frontend 1.0.0
- 相关依赖：Vue 3.4+、Pinia 2.1+

## 定位过程
- 关键线索：KnowledgeBaseList 组件的"新建知识库"按钮使用 `@click="emit('create')"` 发射事件，但点击无反应说明事件未被父组件接收
- 排查路径：
  1. 检查 KnowledgeBaseList.vue → 按钮正确 emit 'create' 事件（第 69 行）
  2. 检查 KnowledgeBasePage.vue → `<KnowledgeBaseList />` 未监听 `@create` 事件（第 26 行）
  3. 确认 KnowledgeBasePage.vue 也未引入 CreateKnowledgeBaseDialog 组件
- 根因说明：KnowledgeBasePage.vue 作为父组件，未监听子组件 KnowledgeBaseList 的 `create` 事件，也未渲染 CreateKnowledgeBaseDialog 组件。事件发射后无人接收，导致按钮点击无任何效果。

## 修复方案
- 修改点说明：在 KnowledgeBasePage.vue 中：
  1. 引入 `CreateKnowledgeBaseDialog` 组件和 `ref`
  2. 新增 `showCreateDialog` 响应式变量控制弹窗显示
  3. 为 `<KnowledgeBaseList>` 添加 `@create="showCreateDialog = true"` 事件监听
  4. 在模板中添加 `<CreateKnowledgeBaseDialog v-model:visible="showCreateDialog" />`
- 影响评估：仅影响知识库管理页面，不涉及其他功能模块
- 风险点：无（纯 UI 事件绑定修复，不涉及数据流或状态管理变更）
- 回滚方案：移除 `@create` 监听和 `CreateKnowledgeBaseDialog` 组件引用即可恢复

## 变更内容
- 代码/配置改动摘要：KnowledgeBasePage.vue 新增 CreateKnowledgeBaseDialog 引入、showCreateDialog 状态、@create 事件监听和弹窗组件渲染
